# ERP.2026.12 — ПФ «Накладная на перемещение (НП)»

## Назначение

Печатная форма «Накладная на перемещение (НП)» для документа **Перемещение товаров**.

Отличие от типовой: в подписях заполняются **Отпустил** / **Получил** материально ответственными складов-отправителя и получателя (параметры макета, как в `нп_ПечатьМ11`). Если на дату документа в `РегистрСведений.Заместители` есть замещение — выводится замещающий (должность — из кадровых данных).

Штатная команда «Накладная на перемещение» не скрывается — обе доступны рядом.

Исходники: `ExternalDataProcessors/нп_ПФ_НакладнаяНаПеремещение/`

Эталон формы отладки и параметров подписей: `ExternalDataProcessors/тн_ПФ_М11_ВнутреннееПотребление/Новая папка/М11/нп_ПечатьМ11`.

Макет `ПФ_MXL_НакладнаяНаПеремещение` — копия типового с параметрами `ДолжностьОтправителя`, `ФИООтправителя`, `ДолжностьПолучил`, `ФИОПолучил`. Тело: `Templates/.../Ext/Template.xml` (для XML-выгрузки обязательно **`.xml`**, не `.mxlx`).

## Сборка .epf

Готовый файл: `нп_ПФ_НакладнаяНаПеремещение.epf` (рядом с `нп_ПФ_НакладнаяНаПеремещение.xml`).

CLI-сборка (платформа 8.3.27, пустая файловая ИБ) собирает обработку **без формы отладки** — для печати через доп. обработки этого достаточно. Форма отладки остаётся в исходниках; полный `.epf` с формой:

1. Конфигуратор **в базе ERP** → **Файл → Открыть** → каталог `нп_ПФ_НакладнаяНаПеремещение` (файл `нп_ПФ_НакладнаяНаПеремещение.xml`).
2. **Файл → Сохранить как…** → `нп_ПФ_НакладнаяНаПеремещение.epf`.

Подробнее: `C:\Projects\Instructions\внешние-обработки.md`.

## Отладка без регистрации

1. В режиме 1С: **Файл → Открыть** → `.epf` (собранный из конфигуратора ERP — с формой).
2. Укажите документ «Перемещение товаров» → **Сформировать**.

## Регистрация в ИБ

1. **НСИ и администрирование → Печатные формы, отчёты и обработки → Дополнительные отчёты и обработки**.
2. Создать элемент, загрузить `.epf`.
3. Назначение: документ «Перемещение товаров».
4. Публикация: использовать.

Безопасный режим отключён (`БезопасныйРежим = Ложь`) — обработка вызывает серверные API конфигурации.

## Проверка

| Сценарий | Ожидание |
|---|---|
| Заполнены МОЛ обоих складов, замещений нет | Отпустил / Получил — должность и ФИО МОЛ складов |
| На дату документа есть замещение МОЛ отправителя | Отпустил — ФИО заместителя; должность из кадров (иначе — склада) |
| Несколько заместителей | Берётся с наибольшей `ДатаНачала` |
| Пустые МОЛ | ПФ без исключений, поля подписей пустые |
| Заместитель без `ФизическоеЛицо` | Печатается исходный МОЛ склада |
| Операция «внутренняя передача» | Шапка филиалов как в типовой; подписи по тем же правилам |
