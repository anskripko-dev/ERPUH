# Шаблон внешней обработки (не ПФ)

Каркас дополнительной обработки БСП для копирования.

Инструкция: `Instructions/внешние-обработки.md`.

## Как использовать

1. Скопировать каталог `ExternalDataProcessors/_Шаблон_ВнешняяОбработка` → `ExternalDataProcessors/<тн_|нп_>ИмяОбработки`.
2. Переименовать файлы/каталоги и `Name` / `GeneratedType` в XML.
3. **Сгенерировать новые UUID** во всех метаданных (не оставлять uuid шаблона).
4. В `ObjectModule.bsl` выбрать вид:
   - дополнительная обработка → `Разделы`;
   - заполнение / связанные объекты → `Назначение`.
5. Настроить команды (`ОткрытиеФормы` и/или `ВызовСерверногоМетода` + `ВыполнитьКоманду`).
6. Доработать форму под сценарий; для чистой серверной команды форму можно убрать.
7. Написать `README.md` конкретной обработки.

## Сборка .epf

Конфигуратор → **Файл → Открыть** → `_Шаблон_ВнешняяОбработка.xml` → **Сохранить как…** → `.epf`.
