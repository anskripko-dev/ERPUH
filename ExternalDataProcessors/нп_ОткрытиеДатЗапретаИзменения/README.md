# Даты запрета изменения

Внешняя обработка-лаунчер: открывает типовую форму `РегистрСведений.ДатыЗапретаИзменения.Форма.ДатыЗапретаИзменения` через БСП (`ДатыЗапретаИзмененияСлужебныйКлиент.ОткрытьДатыЗапретаИзмененияДанных`).

Исходники: `ExternalDataProcessors/нп_ОткрытиеДатЗапретаИзменения/`

## Сборка .epf

1. Конфигуратор **в базе ERP** → **Файл → Открыть** → каталог `нп_ОткрытиеДатЗапретаИзменения` (файл `нп_ОткрытиеДатЗапретаИзменения.xml`).
2. **Файл → Сохранить как…** → `нп_ОткрытиеДатЗапретаИзменения.epf`.

## Использование

- **Файл → Открыть** → `.epf` — сразу откроется типовая форма дат запрета.
- Или регистрация в **Дополнительные отчёты и обработки** (вид: дополнительная обработка, команда «Даты запрета изменения»).

Нужны права на просмотр дат запрета (`ЧтениеДатЗапретаИзменения` / `ДобавлениеИзменениеДатЗапретаИзменения`).
