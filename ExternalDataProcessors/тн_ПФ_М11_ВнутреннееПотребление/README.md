# ERP.2026.9 — внешняя ПФ М-11

## Назначение

Внешняя печатная форма «Требование-накладная М-11 (внешняя)» для документа **Внутреннее потребление** с операцией **Списание на расходы** (`ХозяйственнаяОперация = СписаниеТоваровПоТребованию`).

Для других операций печать не формируется (документы пропускаются с сообщением).

Исходники: `ExternalDataProcessors/тн_ПФ_М11_ВнутреннееПотребление/`

Макет `ПФ_MXL_М11` — копия типового бланка М-11 с областями **Примечание** и **Комиссия** в стиле подвала бланка.

## Сборка .epf

1. Конфигуратор → **Файл → Открыть** → каталог `тн_ПФ_М11_ВнутреннееПотребление` (файл `тн_ПФ_М11_ВнутреннееПотребление.xml`).
2. **Файл → Сохранить как…** → `тн_ПФ_М11_ВнутреннееПотребление.epf`.

Подробнее: `C:\Projects\Instructions\внешние-обработки.md`.

## Отладка без регистрации

1. В режиме 1С: **Файл → Открыть** → `.epf`.
2. Откроется форма отладки: укажите документ «Внутреннее потребление» → **Сформировать**.
3. Результат отобразится в поле табличного документа на форме.

Команда печати через «Дополнительные отчёты и обработки» при этом не нужна.

## Регистрация в ИБ

1. **НСИ и администрирование → Печатные формы, отчёты и обработки → Дополнительные отчёты и обработки**.
2. Создать элемент, загрузить `.epf`.
3. Назначение: документ «Внутреннее потребление».
4. Публикация: использовать.

Безопасный режим отключён (`БезопасныйРежим = Ложь`) — обработка вызывает серверные API конфигурации.

## Проверка

| Сценарий | Ожидание |
|---|---|
| Заполнены `тн_ОтветственныйСотрудник`, `тн_Затребовал`, руководитель орг. | Через кого / Затребовал / Разрешил / Отпустил / Получил заполнены |
| Операция ≠ «Списание на расходы» | Документ пропущен, сообщение пользователю |
| Есть строки Товары | Типовая ТЧ М-11 + таблица в «Примечание» с тем же числом строк |
| Есть `тн_ПриказНаКомиссиюПоИнвентаризации` (Орг+Подр+Склад, дата ≤ списания) | Блок комиссии из среза `тн_Комиссии` на дату списания |
| Нет приказа | Блок комиссии отсутствует, остальное без ошибок |
| Пустые физлица / частичная комиссия | ПФ без исключений |
