# ERP.2026.10 — внешняя ПФ МБ-7

## Назначение

Внешняя печатная форма «Ведомость учета выдачи спецодежды МБ-7 (внешняя)» для документа **Внутреннее потребление** с операцией **Передача в эксплуатацию** (`ХозяйственнаяОперация = ПередачаВЭксплуатацию`).

Для других операций печать не формируется (документы пропускаются с сообщением).

Исходники: `ExternalDataProcessors/тн_ПФ_МБ7_ВнутреннееПотребление/`

Макет `ПФ_MXL_МБ7_ru` — копия типового с областями «Примечание» (встроен в обработку, `ПолучитьМакет`).

Тело макета: `Templates/ПФ_MXL_МБ7_ru/Ext/Template.xml` (для XML-выгрузки обязательно **`.xml`**, не `.mxlx` — иначе в конфигураторе макет пустой).

## Сборка .epf

1. Конфигуратор → **Файл → Открыть** → каталог `тн_ПФ_МБ7_ВнутреннееПотребление` (файл `тн_ПФ_МБ7_ВнутреннееПотребление.xml`).
2. **Файл → Сохранить как…** → `тн_ПФ_МБ7_ВнутреннееПотребление.epf`.

Подробнее: `C:\Projects\Instructions\внешние-обработки.md`.

## Регистрация в ИБ

1. **НСИ и администрирование → Печатные формы, отчёты и обработки → Дополнительные отчёты и обработки**.
2. Создать элемент, загрузить `.epf`.
3. Назначение: документ «Внутреннее потребление».
4. Публикация: использовать.

Безопасный режим отключён (`БезопасныйРежим = Ложь`) — обработка вызывает серверные API конфигурации.

## Проверка

| Сценарий | Ожидание |
|---|---|
| Операция «Передача в эксплуатацию», разные `ФизическоеЛицо` в товарах | В подписях — отдельная строка МОЛ (должность + ФИО) на каждое физлицо |
| Операция «Передача в эксплуатацию», руководитель подразделения | Подпись руководителя подразделения с должностью |
| Операция ≠ «Передача в эксплуатацию» | Документ пропущен, сообщение пользователю |
| Есть строки Товары | Типовая ТЧ МБ-7 + таблица в «Примечание» с тем же числом строк |
| Пустые физлица / должности | ПФ без исключений |
