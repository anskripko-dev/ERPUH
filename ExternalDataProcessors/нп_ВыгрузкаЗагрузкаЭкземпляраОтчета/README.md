# Выгрузка / загрузка экземпляра отчета

Внешняя обработка для переноса документа **Экземпляр отчета** (`НастраиваемыйОтчет`) **вместе с цифрами** через XML-файл.

Цифры в документе не хранятся: они в `ВерсииЗначенийПоказателей` и регистрах `ЗначенияПоказателейОтчетов*`. Копирование только документа даёт пустую форму.

Исходники: `ExternalDataProcessors/нп_ВыгрузкаЗагрузкаЭкземпляраОтчета/`

## Сборка .epf

1. Конфигуратор **в базе ERP** → **Файл → Открыть** → каталог `нп_ВыгрузкаЗагрузкаЭкземпляраОтчета` (файл `нп_ВыгрузкаЗагрузкаЭкземпляраОтчета.xml`).
2. **Файл → Сохранить как…** → `нп_ВыгрузкаЗагрузкаЭкземпляраОтчета.epf`.

## Как перенести из копии

1. В **копии** базы: Файл → Открыть → `.epf` → вкладка **Выгрузка**.
2. Добавьте экземпляр(ы) отчёта. По умолчанию выгружаются только активные нечерновые версии.
3. **Выгрузить в файл** → сохраните `*.xml`.
4. В **рабочей** базе откройте ту же обработку → вкладка **Загрузка**.
5. **Загрузить из файла** → выберите XML. В протоколе — сколько документов, версий и записей записано.
6. Откройте экземпляр отчёта и проверьте цифры.

Нужны права на запись вида отчёта (типовой `ПередЗаписью` проверяет матрицу доступа до `ОбменДанными.Загрузка`). Безопасный режим выключен.

Текущая версия обработки в `СведенияОВнешнейОбработке` — **1.6**. После правки исходников **обязательно** пересоберите `.epf` (Файл → Открыть каталог → Сохранить как) и, если обработка зарегистрирована в доп. обработках, замените файл в карточке. Иначе 1С продолжает открывать старую сборку.

В протоколе загрузки должны появиться строки «Обработка версии 1.6», «Удалены прежние данные экземпляра…» (или «Прежних версий не найдено»), «Записан документ…». Если только «Загружено: документов 0» — открыта не та сборка.

## Что в файле

Корень `нп_ПакетЭкземпляровОтчетов` (`ВерсияФормата="1.0"`):

1. `Описание` — список экземпляров (номер, период, организация) для контроля.
2. Документы `НастраиваемыйОтчет` (GUID сохраняются).
3. `ОписаниеВерсий` и `ВерсииЗначенийПоказателей`.
4. Наборы РС с измерением `Версия`: `ЗначенияПоказателейОтчетов*`, `ЗначенияПоказателейМоделирование*`, `КомментарииЗначенийПоказателей`.

## Ограничения

- Базы должны быть копиями одной ИБ (совпадают GUID показателей, аналитик, организаций).
- НСИ, присоединённые файлы и состояние согласования не переносятся.
- Перед записью из файла **удаляются все текущие версии и цифры** загружаемых экземпляров (иначе форма суммирует старые версии с новыми).
- Если «Замещать существующие документы» выключен, шапка уже существующего документа не меняется; версии и цифры всё равно заменяются данными из файла.

## Регистрация в ИБ

1. **НСИ и администрирование → Печатные формы, отчёты и обработки → Дополнительные отчёты и обработки**.
2. Создать элемент, загрузить `.epf`.
3. Публикация: использовать.
