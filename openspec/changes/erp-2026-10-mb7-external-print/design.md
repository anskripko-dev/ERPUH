## Context

Заявка **ERP.2026.10**: внешняя ПФ «Ведомость учета выдачи спецодежды (МБ-7)» для `Документ.ВнутреннееПотребление` с операцией «Передача в эксплуатацию».

**Типовой контур:**
- Команда печати: `ВнутреннееПотреблениеЛокализация.ДобавитьКомандыПечати` → `Обработка.ПечатьОбщихФормТМЦВЭксплуатации`, идентификатор `МБ7`
- Данные: `ВнутреннееПотреблениеЛокализация.ДанныеДляПечатнойФормыМБ7`
- Макет: `ПФ_MXL_МБ7_ru` (области: Заголовок, Строка, Подписи)
- В типовом макете МОЛ заполняется ответственным склада; отдельной области «Примечание» нет

**Эталон внешней ПФ:** `ExternalDataProcessors/тн_ПФ_М11_ВнутреннееПотребление` (ERP.2026.9).

## Goals / Non-Goals

**Goals:**
- Внешняя ПФ МБ-7 с регистрацией БСП, назначение — `Документ.ВнутреннееПотребление`
- Переиспользовать типовые данные и таблицу товаров МБ-7
- Дозаполнить подписи по ТЗ; добавить «Примечание»
- Печать только для операции `ПередачаВЭксплуатацию`

**Non-Goals:**
- Изменение типовой обработки и макета в конфигурации
- Блок комиссии (не в ТЗ ERP.2026.10)
- Печать для других операций внутреннего потребления

## Decisions

### 1. Внешняя обработка по образцу M-11

**Решение:** `ExternalDataProcessors/тн_ПФ_МБ7_ВнутреннееПотребление/`, `СведенияОВнешнейОбработке()` + `Печать()`.

### 2. Типовые данные — вызов локализации

**Решение:** `ВнутреннееПотреблениеЛокализация.ДанныеДляПечатнойФормыМБ7` для шапки и типовой ТЧ; дозаполнение подписей и примечания — собственным запросом.

### 3. МОЛ из ТЧ «Товары»

**Решение:** для блока подписей МОЛ брать `ФизическоеЛицо` первой строки ТЧ «Товары» (по `НомерСтроки`); должность — `ТекущиеКадровыеДанныеСотрудников`. Типовое заполнение МОЛ со склада переопределяется.

**Обоснование:** п. 2.1 ТЗ; при нескольких физлицах в строках подпись — по первой строке (аналогично одному блоку подписи на документ).

### 4. Руководитель подразделения

**Решение:** `Подразделение.ТекущийРуководитель`; должность — из `ТекущиеКадровыеДанныеСотрудников` (как в ТЗ для МОЛ).

### 5. Примечание

**Решение:** программный вывод таблицы после области «Подписи» (как в M-11): Номенклатура, `СтатьяРасходов`, аналитика строки (`АналитикаРасходов` / `АналитикаАктивовПассивов`).

### 6. Фильтр операции

**Решение:** печать только при `ХозяйственнаяОперация = ПередачаВЭксплуатацию`; иные документы пропускаются с сообщением.

## Risks / Trade-offs

- [Несколько физлиц в ТЧ] → МОЛ в подписи по первой строке
- [Вызов модулей конфигурации] → `БезопасныйРежим = Ложь`
- [Обновление типового макета МБ-7] → макет подгружается из конфигурации, не копируется
