## ADDED Requirements

### Requirement: External MB-7 print form registration
Система SHALL предоставлять внешнюю печатную форму «Ведомость учета выдачи спецодежды (МБ-7)» для документа `ВнутреннееПотребление`, регистрируемую через подсистему «Дополнительные отчёты и обработки».

#### Scenario: Command available on document
- **WHEN** внешняя обработка зарегистрирована и пользователь открывает печать документа «Внутреннее потребление»
- **THEN** доступна команда внешней печатной формы МБ-7

#### Scenario: Only transfer to operation
- **WHEN** документ с операцией, отличной от «Передача в эксплуатацию»
- **THEN** внешняя ПФ для этого документа не формируется; пользователю выводится сообщение

### Requirement: Preserve typical goods table
Типовая табличная часть МБ-7 SHALL заполняться типовым механизмом без изменения состава колонок.

#### Scenario: Typical rows unchanged
- **WHEN** формируется внешняя ПФ по документу с несколькими строками ТЧ «Товары»
- **THEN** типовая таблица выводится как в штатной МБ-7

### Requirement: Signature fields from document
| Поле ПФ | Источник |
|---|---|
| Материально ответственное лицо (должность, ФИО) | `Товары.ФизическоеЛицо` (первая строка); должность — текущие кадровые данные |
| Руководитель подразделения (должность, ФИО) | `Подразделение.ТекущийРуководитель`; должность — текущие кадровые данные |

#### Scenario: Missing optional fields
- **WHEN** физлицо или должность не заполнены
- **THEN** ПФ формируется без ошибок; пустые поля остаются пустыми

### Requirement: Notes section with materials table
В «Примечании» SHALL выводиться таблица: Номенклатура, Статья списания (`СтатьяРасходов`), Аналитика строки. Число строк MUST совпадать с ТЧ «Товары».

#### Scenario: Notes table mirrors goods rows
- **WHEN** в документе N строк ТЧ «Товары»
- **THEN** в «Примечании» N строк дополнительной таблицы
