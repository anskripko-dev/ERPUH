## ADDED Requirements

### Requirement: Nested transaction is not opened when an outer transaction exists
При записи документа трансляции/корректировки обработка SHALL открывать транзакцию только если внешняя транзакция ещё не активна.

#### Scenario: Reflection is called from an outer transaction
- **WHEN** отражение документа по шаблонам выполняется внутри уже открытой транзакции (расширение ТН)
- **THEN** `ЗаписатьРабочийОбъект` не вызывает `НачатьТранзакцию` повторно и не вызывает `ОтменитьТранзакцию` при ошибке

#### Scenario: Reflection is called without an outer transaction
- **WHEN** отражение выполняется без внешней транзакции
- **THEN** обработка открывает собственную транзакцию, фиксирует её при успехе и отменяет при ошибке

### Requirement: Original exception is not replaced by a secondary query error
После ошибки записи обработка MUST NOT обращаться к базе данных, пока внешняя транзакция активна.

#### Scenario: Write fails inside an outer transaction
- **WHEN** запись документа трансляции вызывает исключение при активной внешней транзакции
- **THEN** исходное исключение пробрасывается вызывающему коду без выполнения запросов протокола
- **AND** пользователь видит исходную причину, а не «В данной транзакции уже происходили ошибки»

#### Scenario: Write fails without an outer transaction
- **WHEN** запись документа трансляции вызывает исключение и внешней транзакции нет
- **THEN** обработка отменяет собственную транзакцию и записывает ошибку в протокол
