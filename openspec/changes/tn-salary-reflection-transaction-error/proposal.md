## Why

Отражение документа «Отражение зарплаты в финансовом учете» по шаблонам падает с сообщением «В данной транзакции уже происходили ошибки». Это вторичная ошибка: исходное исключение глотается во вложенной транзакции, после чего следующий запрос к БД подменяет причину.

## What Changes

- `ЗаписатьРабочийОбъект` больше не открывает вложенную транзакцию, если внешняя уже активна (типичный сценарий расширения ТН).
- После ошибки во внешней транзакции код не обращается к БД (протокол записи), чтобы не маскировать исходное исключение.
- `ОбработатьКорректировкиПоПараметрам` пробрасывает исходное исключение, если транзакция ещё активна, вместо возврата `Неопределено`.

### New Capabilities

- `template-reflection-transaction-safety`: безопасная работа с транзакциями при отражении документов по шаблонам.

- `uhnp/src/CommonModules/КорректировкиЗначенийПоказателей32/Module.bsl`
