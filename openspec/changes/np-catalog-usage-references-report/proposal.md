## Why

Нужно быстро понять, где в информационной базе используются выбранные элементы **номенклатуры** и **контрагентов**: не только список элементов по произвольному отбору (включая дополнительные реквизиты), но и все ссылки на каждый элемент с группировкой по типу значения и количеством. Типовые «места использования» работают по одной ссылке и не дают массовый отчёт с отбором по доп. реквизитам.

## What Changes

- Новое служебное расширение `нп_АнализСсылокСправочников` (префикс `нп_`, назначение Customization)
- Отчёт СКД `нп_МестаИспользованияНоменклатурыИКонтрагентов` в составе расширения: выбор справочника (номенклатура / контрагенты), произвольный отбор включая доп. реквизиты, вывод ссылок с группировкой по типу значения и количеством
- Команда отчёта в подсистеме расширения
- Двойная выгрузка: EDT `src/` и конфигуратор `configurator/` (как у `нп_КонтрольПроведенияПоДО`)

## Capabilities

### New Capabilities
- `catalog-usage-references-report`: отчёт мест использования элементов номенклатуры и контрагентов с произвольным отбором (в т.ч. доп. реквизиты), группировкой ссылок по типам значения и количеством

### Modified Capabilities
- (нет)

## Impact

- Новая поставка: `Extensions/нп_АнализСсылокСправочников/`
- Заимствование: `Справочник.Номенклатура`, `Справочник.Контрагенты`
- Платформенный поиск ссылок (`НайтиПоСсылкам` / `ОбщегоНазначения.МестаИспользования`)
- Не затрагивает: расширение ТН, контроль проведения по ДО, типовые модули форм
