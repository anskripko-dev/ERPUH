## Context

Подписка `ПриИзмененииРегистраБухгалтерииТрансляцияУХ` срабатывает на запись любого набора регистра бухгалтерии. Шаблон «НСБУ - МСФО» привязан к регистру-источнику (`Хозрасчетный`), не к типу документа. «Распределение РБП» при отражении в регл. учёте даёт проводки → подписка пишет РС `ОтражениеДокументовПоШаблонам`.

Типовой флаг `ДокументыНеОтражаемыеПоШаблонам.НеОтражатьМСФО` отключает только `ВыполнитьОтражениеОбъекта` (создание `Трансляция`). `НаборЗаписей.Записать` в `ВыполнитьТрансляциюДокумента` выполняется раньше и роняет закрытие месяца.

Настройкой шаблона тип РБП не исключить: в `ШаблоныТрансляций` нет отбора по документу.

## Goals / Non-Goals

**Goals:**

- Не писать РС `ОтражениеДокументовПоШаблонам` для `РаспределениеРасходовБудущихПериодов`
- Не создавать по РБП документы `Трансляция` / трансформационные корректировки из этой подписки
- Сохранить отражение РБП в БУ/НУ

**Non-Goals:**

- Исключение других типов документов
- Сводная (не подокументная) трансляция как замена
- Автоочистка уже существующих записей РС и документов `Трансляция` по РБП
- Правка шаблона «НСБУ - МСФО» (сломает остальные документы)

## Decisions

1. **Ранний `Возврат` в подписке**, а не флаг «Не отражать МСФО» и не удаление шаблона.
   Точка: `УправлениеОтчетамиУХ.ПриИзмененииРегистраБухгалтерииТрансляцияПриЗаписи` до вызова `КорректировкиЗначенийПоказателей32`.
   Дубль проверки — в `ПриИзмененииРегистраБухгалтерииТрансляция` (прямой вызов писателя).

2. **Критерий — тип ссылки**, не наименование шаблона и не организация. Правило методическое: РБП не идут в МСФО.

3. Существующие записи РС по зависшим РБП не удаляются кодом. После выката подписка их больше не перезаписывает; закрытие месяца не падает. Незавершённые (`ОбработкаВыполнена = нет`) лучше снять вручную, чтобы регламентное задание не обработало очередь.

## Risks / Trade-offs

- Правка типовых общих модулей, не расширения `uhnp.НП`. При обновлении УХ перенести вставку. Предпочтительно затем вынести `&Вместо` в расширение.
- Если по РБП уже есть проведённые `Трансляция`, они не сторнируются. Нужна ручная проверка.
- Регламентное задание `ОтражениеДокументовПоШаблонам` может взять старые незавершённые записи РБП — поэтому очистка очереди желательна.
