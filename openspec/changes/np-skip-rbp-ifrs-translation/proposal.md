## Why

Закрытие месяца по «Завод Николь-Пак» (август 2026) падает на шаге «Отражение документов в регламентированном учете»: три «Распределение РБП» пишут РС `ОтражениеДокументовПоШаблонам` по шаблону НСБУ–МСФО и получают «Запись с такими ключевыми полями существует». По методике РБП **не должны** отражаться по МСФО. Типовая подписка транслирует любой документ с проводками в регистре-источнике шаблона, без отбора по типу.

## What Changes

- Ранний выход из подокументной трансляции, если регистратор — `Документ.РаспределениеРасходовБудущихПериодов`.
- РС `ОтражениеДокументовПоШаблонам` для РБП не пишется; документ `Трансляция` не создаётся.
- Отражение РБП в БУ/НУ (регл. учёт) не меняется.

## Capabilities

### New Capabilities

- `rbp-excluded-from-ifrs-translation`: тип «Распределение РБП» исключён из трансляции НСБУ–МСФО

### Modified Capabilities

- (нет — в `openspec/specs/` нет capability по трансляции МСФО)

## Impact

- Типовые модули (точка подписки УХ):
  - `CommonModule.УправлениеОтчетамиУХ` — `ПриИзмененииРегистраБухгалтерииТрансляцияПриЗаписи`
  - `CommonModule.КорректировкиЗначенийПоказателей32` — `ПриИзмененииРегистраБухгалтерииТрансляция`
- Не затрагивает: шаблон «НСБУ - МСФО» для прочих документов, сводную трансляцию по другим типам, расширение `uhnp.ТН`
- Данные: после выката для трёх зависших РБП августа 2026 закрытие можно повторить; старые незавершённые записи РС по РБП лучше удалить, чтобы регламентное задание не создало `Трансляция`
