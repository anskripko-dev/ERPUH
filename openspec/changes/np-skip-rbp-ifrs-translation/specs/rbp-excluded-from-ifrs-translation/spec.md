## ADDED Requirements

### Requirement: RBP documents skip template translation
При записи движений регистра бухгалтерии система MUST NOT выполнять подокументную трансляцию НСБУ–МСФО, если регистратор — `Документ.РаспределениеРасходовБудущихПериодов`. Система MUST NOT писать РС `ОтражениеДокументовПоШаблонам` и MUST NOT создавать документы `Трансляция` / трансформационные корректировки из этой подписки для такого регистратора.

#### Scenario: Month-end reflection of RBP in regulated accounting
- **WHEN** закрытие месяца отражает «Распределение РБП» в регламентированном учёте и записывает набор `Хозрасчетный`
- **THEN** подписка `ПриИзмененииРегистраБухгалтерииТрансляцияУХ` завершается без записи РС `ОтражениеДокументовПоШаблонам`
- **AND** отражение в БУ/НУ не отменяется из-за трансляции МСФО

#### Scenario: Other documents still translate
- **WHEN** записывается набор бухгалтерии с регистратором другого типа (не «Распределение РБП»)
- **THEN** подокументная трансляция выполняется как раньше, включая шаблон НСБУ–МСФО

#### Scenario: Clearing RBP accounting movements
- **WHEN** набор бухгалтерии по «Распределение РБП» записывается пустым (отмена проведения / очистка движений)
- **THEN** подписка также не пишет и не пересобирает РС `ОтражениеДокументовПоШаблонам`

### Requirement: Existing IFRS queue does not block regulated accounting
Исключение типа РБП из трансляции MUST позволять повторно выполнить «Отражение документов в регламентированном учете», даже если в РС `ОтражениеДокументовПоШаблонам` уже есть незавершённые записи по этим документам: подписка больше не пытается добавить строку с тем же ключом.

#### Scenario: Retry after duplicate-key failure
- **WHEN** ранее закрытие месяца упало с «Запись с такими ключевыми полями существует» по РБП и шаблону НСБУ–МСФО
- **AND** в конфигурации действует исключение типа РБП
- **THEN** повтор отражения в регл. учёте не вызывает эту запись регистра и не устанавливает `Отказ` из трансляции
