## Context

В `ЕстьПравоОбходаКонтроля` полноправный пользователь всегда получает обход. Для теста под админом это мешает.

## Goals / Non-Goals

**Goals:**
- Глобальный флаг «контролировать и полноправных»
- По умолчанию поведение как сейчас (обход полноправных)
- Роль `нп_ПроведениеБезСогласованияДО` продолжает обходить независимо от флага

**Non-Goals:**
- Не менять правила контроля по организациям/типам
- Не заводить отдельный профиль тестировщика

## Decisions

1. **Константа** `нп_КонтролироватьПроведениеДОДляПолноправных` (Булево, по умолчанию Ложь) — один тумблер в подсистеме, без измерения по организации.
2. При `Истина` ветка `ЭтоПолноправныйПользователь` не даёт обход; дальше только `РольДоступна(нп_ПроведениеБезСогласованияДО)`.
3. Не использовать `Пользователи.РолиДоступны` — у полноправных она возвращает Истина для любой «обычной» роли.
4. Чтение константы — в привилегированном режиме (на случай отсутствия прав у сеанса).

## Risks / Trade-offs

- Админ с явно назначенной ролью обхода всё равно обойдёт — это ожидаемо.
- Константа «забытая» во включённом состоянии ужесточает прод — синоним/README должны явно говорить про тест/отладку.
