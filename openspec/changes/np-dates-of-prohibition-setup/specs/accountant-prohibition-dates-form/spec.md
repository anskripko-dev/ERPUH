## ADDED Requirements

### Requirement: Accountant form without full register rights
Система SHALL предоставлять обработку `нп_УстановкаДатЗапретаИзменения` для установки дат запрета по организациям. Пользователь с ролью `нп_УстановкаДатЗапретаПоОрганизациям` MUST иметь доступ к этой обработке и MUST NOT получать права на просмотр/изменение всего типового РС `ДатыЗапретаИзменения` и типовой формы администрирования.

#### Scenario: Accountant opens own form
- **WHEN** пользователь с ролью `нп_УстановкаДатЗапретаПоОрганизациям` открывает обработку
- **THEN** отображается форма установки дат по доступным организациям без открытия `РегистрСведений.ДатыЗапретаИзменения.Форма.ДатыЗапретаИзменения`

#### Scenario: Typical admin form stays restricted
- **WHEN** у пользователя нет `ДобавлениеИзменениеДатЗапретаИзменения` / `ЧтениеДатЗапретаИзменения`
- **THEN** типовая форма дат запрета и список записей всего регистра недоступны

### Requirement: Organization scope on server
Запись в типовой РС MUST выполняться на сервере только по организациям, к которым у пользователя есть доступ в обработке. Клиентский отбор MUST NOT быть единственной защитой.

#### Scenario: Write for allowed organization
- **WHEN** бухгалтер сохраняет дату или N по организации из своего списка
- **THEN** система записывает ключи типового РС (раздел + эта организация + адресат «для всех пользователей»)

#### Scenario: Write for foreign organization is rejected
- **WHEN** запрос записи содержит организацию вне доступного пользователю списка
- **THEN** запись не выполняется, пользователю выводится отказ

### Requirement: Auto-shift settings from the form
Форма SHALL позволять включить автосдвиг и задать N дней по организации. Эти настройки MUST храниться в РС `нп_НастройкиАвтосдвигаДатЗапрета`, а не подменять типовые относительные даты («конец прошлого месяца»).

#### Scenario: Enable auto-shift for organization
- **WHEN** бухгалтер указывает N > 0 и включает автосдвиг по организации
- **THEN** в настройках сохраняется пара (организация, N), и следующее выполнение задания применяет `сегодня − N` к ключам механизма по этой организации (если нет живого окна заявки)

### Requirement: Create opening request from the form
Форма SHALL позволять создать документ `нп_ЗаявкаНаОткрытиеПериода` по выбранным организациям без перехода в администрирование регистра.

#### Scenario: Accountant creates request
- **WHEN** бухгалтер заполняет организации, срок в днях, период «с … по …» и опционально раздел и записывает заявку
- **THEN** создаётся непроведённый/черновой документ заявки, готовый к отправке на согласование в ДО 3
