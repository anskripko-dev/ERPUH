## ADDED Requirements

### Requirement: Excel load for organizations
Система SHALL загружать список организаций из табличного файла (Excel / табличный документ) в обработку `нп_УстановкаДатЗапретаИзменения`. Разбор файла MUST использовать типовые приёмы подсистемы «Загрузка данных из файла» (табличный документ, сопоставление колонок, протокол ошибок). РС `ДатыЗапретаИзменения` MUST NOT регистрироваться в типовом списке загружаемых справочников.

#### Scenario: Load valid spreadsheet
- **WHEN** бухгалтер выбирает файл с колонкой организации и заполненными N и/или датой
- **THEN** строки сопоставляются со справочником `Организации`, ошибки выводятся построчно, корректные строки попадают в таблицу формы

#### Scenario: Unknown organization is reported
- **WHEN** в файле указано наименование/код, которому нет однозначного элемента `Организации`
- **THEN** строка не записывается в регистр, в протоколе фиксируется ошибка сопоставления

### Requirement: Apply loaded rows within access scope
Применение загруженных строк MUST писать только по организациям из доступного бухгалтеру списка и только ключи механизма (раздел с типом объекта «Организации» + организация + «для всех пользователей»).

#### Scenario: N column upserts auto-shift
- **WHEN** в строке задано N > 0 по доступной организации
- **THEN** система обновляет `нп_НастройкиАвтосдвигаДатЗапрета` для этой организации

#### Scenario: Date column writes typical register once
- **WHEN** в строке задана абсолютная дата и организация доступна
- **THEN** система записывает `ДатаЗапрета` в типовой РС по ключам механизма; если N не задан, организация MUST NOT включаться в автосдвиг только из-за этой даты

#### Scenario: Foreign organization in file is skipped
- **WHEN** сопоставленная организация не входит в доступный бухгалтеру список
- **THEN** строка не применяется, в протоколе фиксируется отказ по правам

### Requirement: Optional section column
Колонка раздела учёта MAY быть пустой. Пустой раздел MUST означать все разделы дат запрета, у которых в `ТипыОбъектов` есть `СправочникСсылка.Организации`. Разделы «Банк», «Касса», «Складские операции», «Бюджетирование», «Планирование» при пустом разделе MUST NOT заполняться.

#### Scenario: Empty section applies organization-typed sections
- **WHEN** в строке раздел не указан
- **THEN** запись/автосдвиг действует на разделы с типом объекта «Организации»

#### Scenario: Explicit section is limited
- **WHEN** в строке указан существующий раздел дат запрета с типом «Организации»
- **THEN** применяется только этот раздел
