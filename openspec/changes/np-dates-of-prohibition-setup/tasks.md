## 1. Метаданные расширения НП

- [ ] 1.1 Создать РС `нп_НастройкиАвтосдвигаДатЗапрета` (организация, N, включено) с формой списка/записи
- [ ] 1.2 Создать документ `нп_ЗаявкаНаОткрытиеПериода` (ТЧ организации; K дней; период с/по; раздел опционально) со стандартными подписками БИД на форме
- [ ] 1.3 Создать регламентное задание `нп_СдвигДатЗапретаИзменения` и общий модуль `нп_ДатыЗапретаИзменения`
- [ ] 1.4 Включить объекты в подсистему расширения НП; префикс `нп_`; области модулей по стандартам
- [ ] 1.5 Не создавать обработку `нп_УстановкаДатЗапретаИзменения`, роль `нп_УстановкаДатЗапретаПоОрганизациям` и загрузку из Excel

## 2. Запись в типовой РС

- [ ] 2.1 Реализовать запись ключей механизма: раздел (организации-типы или явный), объект = организация, адресат «для всех пользователей», абсолютная `ДатаЗапрета`, пустое относительное описание
- [ ] 2.2 Писать типовой РС только из задания и из серверной логики после `Согласован` (не из пользовательской формы установки дат)
- [ ] 2.3 Не изменять персональные строки, кассу/склад/сценарии/БС
- [ ] 2.4 После набора записей — типовое обновление действующих дат запрета

## 3. Автосдвиг

- [ ] 3.1 Обработчик задания: по включённым настройкам вычислить `сегодня − N`
- [ ] 3.2 Если по организации есть согласованная заявка со сроком действия открытого периода, который не истёк — не писать `сегодня − N` по ключам этой заявки
- [ ] 3.3 Привилегированная запись, не блокируемая датой запрета
- [ ] 3.4 Журнал регистрации: организация, старая/новая дата, режим (автосдвиг / заявка)

## 4. Заявка и ДО 3

- [ ] 4.1 Проверка заполнения: организации, K > 0, период с ≤ по
- [ ] 4.2 Интеграция формы с `ИнтеграцияС1СДокументооборот3` / базовой функциональностью БИД (как у пилотных документов)
- [ ] 4.3 По `Согласован`: записать в типовой РС отсечку `ПериодС − 1 день` по ключам заявки
- [ ] 4.4 Несогласованная / на согласовании заявка РС не меняет
- [ ] 4.5 Подсказка на форме: отсечка БСП откроет всё после `ПериодС − 1`, не только выбранный месяц
- [ ] 4.6 Ошибка сервиса ДО при отправке — заявка не считается согласованной

## 5. Проверка

- [ ] 5.1 Автосдвиг без заявки: граница = сегодня − N, на следующий день сдвигается
- [ ] 5.2 Заявка 5 дней: срок действия открытого периода от даты согласования; пока он не истёк, задание не откатывает; после истечения снова N
- [ ] 5.3 Персональная дата пользователя не перезаписывается
- [ ] 5.4 Несогласованная заявка не меняет типовой РС; ошибка ДО не ставит «Согласован»
- [ ] 5.5 Сверить стиль со стандартами 1С и префиксом `нп_`
