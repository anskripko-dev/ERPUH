## 1. Метаданные расширения НП

- [ ] 1.1 Создать РС `нп_НастройкиАвтоматическойУстановкиДатЗапрета` (организация, Пользователи (пользователь/группа пользователей), раздел учёта необязательно, N, включено) с формой списка/записи
- [ ] 1.2 Создать документ `нп_ЗаявкаНаОткрытиеПериода` (ТЧ организации; K дней; период с/по; раздел опционально) со стандартными подписками БИД на форме
- [ ] 1.3 Создать регламентное задание `нп_СдвигДатЗапретаИзменения` и общий модуль `нп_ДатыЗапретаИзменения`
- [ ] 1.4 Включить объекты в подсистему расширения НП; префикс `нп_`; области модулей по стандартам
- [ ] 1.5 Не создавать обработку `нп_УстановкаДатЗапретаИзменения`, роль `нп_УстановкаДатЗапретаПоОрганизациям` и загрузку из Excel

## 2. Запись в типовой РС

- [ ] 2.1 Запись: раздел (из настройки/заявки или все с типом «Организации»), объект = организация, Пользователи из настройки, абсолютная `ДатаЗапрета`, пустое относительное описание
- [ ] 2.2 Писать типовой РС только из задания и из серверной логики после `Согласован`
- [ ] 2.3 Не изменять записи вне настроек, кассу/склад/сценарии/БС при пустом разделе
- [ ] 2.4 После набора записей — типовое обновление действующих дат запрета

## 3. Автоматическая установка

- [ ] 3.1 Обработчик: по включённым настройкам вычислить `сегодня − N` этой настройки
- [ ] 3.2 Если есть согласованная заявка, покрывающая организацию и раздел настройки, — не писать `сегодня − N` в эти записи
- [ ] 3.3 Привилегированная запись, не блокируемая датой запрета
- [ ] 3.4 Журнал регистрации: организация, Пользователи, раздел, старая/новая дата, режим (автоматическая установка / заявка)

## 4. Заявка и ДО 3

- [ ] 4.1 Проверка заполнения: организации, K > 0, период с ≤ по
- [ ] 4.2 Интеграция формы с `ИнтеграцияС1СДокументооборот3` / базовой функциональностью БИД
- [ ] 4.3 По `Согласован`: записать отсечку `ПериодС − 1 день` по организациям, разделу и Пользователям настроек (если настроек нет — «для всех пользователей»)
- [ ] 4.4 Несогласованная / на согласовании заявка РС не меняет
- [ ] 4.5 Подсказка на форме: отсечка БСП откроет всё после `ПериодС − 1`, не только выбранный месяц
- [ ] 4.6 Ошибка сервиса ДО при отправке — заявка не считается согласованной

## 5. Проверка

- [ ] 5.1 Автоматическая установка без заявки: граница = сегодня − N, на следующий день сдвигается
- [ ] 5.2 Разные N у «для всех» и у пользователя; разные N без раздела и по разделу МСФО
- [ ] 5.3 Заявка 5 дней: срок действия открытого периода от даты согласования; покрытые записи не откатываются; прочие разделы той же организации продолжают автоматическую установку
- [ ] 5.4 Дата только из типовой формы, без настройки, не перезаписывается
- [ ] 5.5 Несогласованная заявка не меняет типовой РС; ошибка ДО не ставит «Согласован»
- [ ] 5.6 Сверить стиль со стандартами 1С и префиксом `нп_`
