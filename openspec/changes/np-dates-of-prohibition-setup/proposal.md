## Why

Типовой механизм БСП «Даты запрета изменения» в ERP УХ умеет проверять период, но неудобен для холдинга: даты ставятся вручную по разделам, нет массовой загрузки из Excel, нет согласованного временного открытия периода, абсолютные даты сами не едут, а типовая форма требует прав на весь регистр. Бухгалтерам нужна своя установка дат без администрирования РС.

## What Changes

- Форма бухгалтера (обработка `нп_УстановкаДатЗапретаИзменения`) без прав на весь типовой РС: только «свои» организации
- Массовая загрузка из Excel с разбором файла по образцу типовой «Загрузки данных из файла» (не включение РС в список справочников — туда регистр добавить нельзя)
- Регламентное задание: для настроек автосдвига писать в типовой РС абсолютную дату `сегодня − N`
- Документ `нп_ЗаявкаНаОткрытиеПериода` с бесшовным согласованием в ДО 3; после `Согласован` на срок K дней в тот же РС пишется более ранняя отсечка по открываемому периоду; по истечении окна снова `сегодня − N`
- Роль `нп_УстановкаДатЗапретаПоОрганизациям`; запись в типовой РС — узкий набор ключей на сервере
- Типовые подписки проверки, модули БСП и формы ТН на РС **не менять**

## Capabilities

### New Capabilities

- `accountant-prohibition-dates-form`: форма бухгалтера без прав администратора на весь регистр дат запрета
- `prohibition-dates-excel-load`: массовая установка из Excel по списку организаций
- `prohibition-dates-auto-shift`: ночной автосдвиг абсолютных дат как `сегодня − N`
- `period-opening-request`: заявка на открытие периода (организации, срок в днях, период, опционально раздел учёта) через согласование ДО 3

### Modified Capabilities

- (нет — в `openspec/specs/` нет зафиксированных capabilities по датам запрета)

## Impact

- Расширение `uhnp.НП` (префикс `нп_`): обработка, документ заявки, РС настроек автосдвига, регламентное задание, роль, общий модуль
- Опционально сборка `.epf` обработки в `ExternalDataProcessors/` (как `нп_ОткрытиеДатЗапретаИзменения`)
- Типовой РС `ДатыЗапретаИзменения` — только запись ключей механизма (раздел + организация + «для всех пользователей»)
- ДО 3: `ИнтеграцияС1СДокументооборот3*`, `ОбъектыИнтегрированныеС1СДокументооборотом`, `СостоянияСогласованияВДокументообороте`
- Не затрагивает: `uhnp.ТН`, типовые формы `тн_*` на РС, лаунчер типовой формы, проверку `ПередЗаписью` БСП
