## ADDED Requirements

### Requirement: Pattern documentation for external processors

Система SHALL предоставлять в репозитории инструкцию по внешним обработкам БСП (виды «Дополнительная обработка», «Заполнение объекта», «Создание связанных объектов»), явно отделённую от паттерна внешних печатных форм.

#### Scenario: Developer opens instruction

- **WHEN** разработчик или агент открывает `Instructions/внешние-обработки.md`
- **THEN** в документе описаны виды обработок, типы команд, `ВыполнитьКоманду`, разделы vs назначение, параметры формы БСП и `ХранилищеНастроек`
- **THEN** печатные формы упоминаются только как отдельный паттерн со ссылкой на `тн_ПФ_*`

### Requirement: Copyable processor skeleton

Система SHALL предоставлять копируемый каркас внешней обработки в `ExternalDataProcessors/_Шаблон_ВнешняяОбработка` с модулем объекта (`СведенияОВнешнейОбработке`, заготовка `ВыполнитьКоманду`) и формой, принимающей параметры БСП.

#### Scenario: New processor from template

- **WHEN** создаётся новая внешняя обработка по шаблону
- **THEN** копируется каталог шаблона, переименовываются метаданные, заменяются UUID
- **THEN** выбирается вид (доп. обработка / заполнение / связанные) и настраиваются команды через функции `ДополнительныеОтчетыИОбработкиКлиентСервер`
