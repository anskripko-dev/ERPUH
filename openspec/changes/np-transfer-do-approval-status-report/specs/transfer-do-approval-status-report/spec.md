## ADDED Requirements

### Requirement: External report registration
Система SHALL предоставлять внешний отчёт «Состояние согласования ДО по перемещениям» (префикс `нп_`), регистрируемый через подсистему «Дополнительные отчёты и обработки» с видом «Дополнительный отчёт».

#### Scenario: Report opens from additional reports
- **WHEN** отчёт зарегистрирован и пользователь выбирает его команду открытия формы
- **THEN** открывается форма отчёта СКД и доступно формирование по настройкам варианта

#### Scenario: Safe mode read-only
- **WHEN** отчёт регистрируется в ИБ
- **THEN** в сведениях о внешней обработке указан вид `ДополнительныйОтчет` и безопасный режим включён (только чтение)

### Requirement: List transfer documents with DO approval state
Отчёт SHALL выводить список документов `ПеремещениеТоваров` за выбранный период с полями: ссылка, дата, номер, организация, склад-отправитель, склад-получатель, проведён, пометка удаления, логистический статус документа, признак связи с ДО, состояние согласования в ДО и его представление.

Источник состояния — типовые регистры `ОбъектыИнтегрированныеС1СДокументооборотом` и `СостоянияСогласованияВДокументообороте` (без веб-вызова в Документооборот).

#### Scenario: Approved document
- **WHEN** перемещение связано с объектом ДО и в регистре состояний значение `Согласован`
- **THEN** в строке отчёта `ЕстьСвязьСДО = Истина`, состояние = `Согласован`, представление содержит согласованное состояние

#### Scenario: On approval
- **WHEN** перемещение связано с ДО и состояние `НаСогласовании`
- **THEN** строка показывает это состояние; документ остаётся в выборке периода

#### Scenario: No DO link
- **WHEN** для перемещения нет записи в `ОбъектыИнтегрированныеС1СДокументооборотом`
- **THEN** `ЕстьСвязьСДО = Ложь`, представление состояния = «Нет связи с Документооборотом»

#### Scenario: Linked but state empty
- **WHEN** связь с ДО есть, а состояние в регистре не заполнено
- **THEN** представление = «Связан с ДО, состояние не задано»

### Requirement: Filters for operational monitoring
Отчёт SHALL позволять отбирать данные по периоду дат документа (обязательно), организации, складам отправителя/получателя, признаку проведения, наличию связи с ДО и состоянию согласования.

#### Scenario: Period filter
- **WHEN** заданы начало и конец периода
- **THEN** в результат попадают только перемещения с датой в этом интервале

#### Scenario: Filter by missing DO link
- **WHEN** пользователь отбирает документы без связи с ДО
- **THEN** в результат попадают только строки с `ЕстьСвязьСДО = Ложь`

### Requirement: Re-approval flag from control extension
При наличии регистра `нп_ПризнакиПересогласованияДО` отчёт SHALL выводить признак `ТребуетсяПересогласование` для документа (отсутствие записи трактуется как Ложь).

#### Scenario: Document marked for re-approval
- **WHEN** в РС `нп_ПризнакиПересогласованияДО` для перемещения установлен `ТребуетсяПересогласование`
- **THEN** соответствующая колонка отчёта показывает Истина

#### Scenario: No re-approval record
- **WHEN** записи признака для документа нет
- **THEN** колонка `ТребуетсяПересогласование` показывает Ложь
