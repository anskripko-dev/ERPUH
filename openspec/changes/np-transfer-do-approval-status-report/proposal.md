## Why

Контроль проведения перемещений по согласованию в 1С:Документооборот уже работает (расширение `нп_КонтрольПроведенияПоДО`), статус виден на форме документа. Для операционного контроля нужен **списочный** срез: какие «Перемещения товаров» не связаны с ДО, на согласовании, согласованы, требуют пересогласования — без открытия каждого документа.

## What Changes

- Новый **внешний отчёт** (СКД, регистрация БСП «Дополнительные отчёты и обработки», вид «Дополнительный отчёт») по документам `ПеремещениеТоваров`
- Вывод состояния согласования из типовых регистров интеграции с ДО (без веб-вызова в ДО)
- Отборы: период, организация, склады, проведённость, состояние согласования / наличие связи с ДО
- Признак «требуется пересогласование» из РС расширения `нп_ПризнакиПересогласованияДО` (если расширение установлено)
- Исходники — `ExternalReports/нп_СостояниеСогласованияДОПеремещений/` (префикс `нп_`); типовая конфигурация и расширение контроля не правятся ради отчёта

## Capabilities

### New Capabilities
- `transfer-do-approval-status-report`: внешний отчёт состояния согласования в ДО по перемещениям товаров

### Modified Capabilities
- (нет)

## Impact

- Документ: `Документ.ПеремещениеТоваров` (чтение: дата, номер, организация, склады, проведён, пометка удаления, статус логистики)
- Типовые регистры ДО (чтение):
  - `РегистрСведений.ОбъектыИнтегрированныеС1СДокументооборотом`
  - `РегистрСведений.СостоянияСогласованияВДокументообороте`
  - `Перечисление.СостоянияСогласованияВДокументообороте`
- Расширение НП (чтение, опционально для колонки пересогласования): `РегистрСведений.нп_ПризнакиПересогласованияДО`
- Поставка: `.erf` через доп. отчёты и обработки; сборка по `Instructions/внешние-обработки.md` / стандарты СКД `Instructions/скд-стандарты-разработки-отчетов.md`
- Не затрагивает: логику запрета проведения, правила интеграции ДО, расширение `uhnp.ТН`
