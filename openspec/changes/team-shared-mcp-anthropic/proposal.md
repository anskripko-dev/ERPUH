## Why

Сейчас MCP для 1С привязан к `localhost` одного разработчика (`.cursor/mcp.json` → `http://localhost:8002/mcp`). Несколько пользователей в одной сети не могут одинаково пользоваться агентом для разработки, аналитики, тестов и инструкций. **Cursor команде не оплачивают**; есть предоплаченные **Claude и GPT**. Нужен общий LAN MCP под эти модели, без обязательного Cursor и без привязки к ещё не выбранному EDT.

## What Changes

- Общий HTTP MCP-шлюз в локальной сети вместо персональных `stdio`/`localhost` серверов
- Четыре профиля доступа: разработка, аналитика, тестирование, инструкции — с разным набором инструментов
- Клиенты команды: предоплаченный **Claude** (Claude Desktop / Claude Code) и предоплаченный **GPT** (ChatGPT-коннекторы / Copilot). Cursor не обязателен и не является командным клиентом
- Канонический каталог MCP-URL в репозитории (не `.cursor/mcp.json` как источник истины)
- Контекст кода и метаданных — из файловой выгрузки конфигурации / git, **без жёсткой привязки к конкретной EDT**
- Запрет продакшена в MCP; аналитика и тесты — только на копиях ИБ
- Правила агента в `AGENTS.md` / OpenSpec, чтобы Claude и GPT видели один контракт

## Capabilities

### New Capabilities

- `shared-mcp-gateway`: единый Streamable HTTP шлюз в LAN с авторизацией, изоляцией сессий и без доступа к продуктивной ИБ
- `mcp-work-profiles`: профили `dev` / `analytics` / `test` / `docs` с явным allowlist инструментов под роли
- `prepaid-agent-workspace`: рабочие места на предоплаченных Claude и GPT, без обязательного Cursor и без зависимости от конкретной EDT

### Modified Capabilities

- (нет — в `openspec/specs/` ещё нет зафиксированных capabilities по MCP)

## Impact

- Репозиторий `ERPUH`: канонический каталог MCP, сниппеты для Claude Desktop и ChatGPT, `AGENTS.md`, документация подключения
- `.cursor/*` — только опциональный экспорт, не командный контур
- LAN-хост `srv-mcp` (вне этого git): шлюз, reverse proxy, токены
- Тестовая / копия ИБ УХ (не прод): HTTP-сервис метаданных и запросов, отдельная ИБ для тестов
- Выгрузка конфигурации `uhnp` / `uhnp.НП` / `uhnp.ТН` как источник кода для агента
- Не затрагивает: оплату Cursor, выбор и закупку EDT, правки типовой УХ, продуктивный кластер 1С
