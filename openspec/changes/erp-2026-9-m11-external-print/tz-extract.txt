Дата регистрации: _14.07.2026___
Доработка внешней печатной формы документа «Внутреннее потребление (Списание на расходы)» 
1. Общие требования
Разработать внешнюю печатную форму на основании типовой печатной формы документа «Внутреннее потребление (Списание на расходы)».
При формировании печатной формы использовать актуальные данные документа.
Типовая табличная часть печатной формы изменению не подлежит.
2. Требования к заполнению печатной формы
2.1. Заполнение реквизитов шапки
Дополнительно реализовать заполнение следующих реквизитов.
Поле печатной формы
Источник данных
Отпустил (должность, подпись)
Вкладка Дополнительно → реквизит Ответственный сотрудник, должность получать из Физ. Лица (Текущие кадровые днные сотрудников – Должность)
Получил (должность, подпись)
Вкладка Дополнительно → реквизит Затребовал, должность получать из Физ. Лица (Текущие кадровые днные сотрудников – Должность)
Через кого
Вкладка Дополнительно → реквизит Ответственный сотрудник
Затребовал
Вкладка Дополнительно → реквизит Затребовал
Разрешил
Справочник Организации → реквизит Руководитель организации, указанной в документе
Остальные реквизиты печатной формы заполняются типовыми механизмами.
3. Дополнительная табличная часть
Типовая табличная часть печатной формы изменению не подлежит.
В разделе «Примечание» необходимо вывести дополнительную табличную часть «Материальные ценности».
Новая табличная часть должна содержать следующие колонки.
№
Наименование колонки
Источник данных
1
Материальные ценности
Табличная часть Товары → Номенклатура
2
Статья списания
Табличная часть Товары → Статья списания
3
Аналитика
Табличная часть Товары → Аналитика
Количество строк новой таблицы должно соответствовать количеству строк табличной части Товары документа.
Новая таблица является дополнительной и не заменяет типовую табличную часть печатной формы.
4. Вывод информации о комиссии
4.1. Источник данных
Документ тн_ПриказНаКомиссиюПоИнвентаризации
Заполнение документа проверяется по Организации, Подразделению, Складу
Если такой документ заполнен, тогда из указанного документа необходимо получать:
председателя комиссии;
членов комиссии.
Если председатель комиссии отсутствует либо отсутствуют отдельные члены комиссии, печатная форма должна формироваться без ошибок. Выводятся только заполненные сведения.
4.2. Логика формирования печатной формы
Необходимо реализовать автоматическую вариативность печатной формы.
Вариант 1. Комиссия задана
Если документ тн_ПриказНаКомиссиюПоИнвентаризации заполнен, необходимо:
получить председателя комиссии;
получить членов комиссии;
вывести блок комиссии в подвале печатной формы.
При выводе информации:
председатель комиссии выводится отдельной строкой;
каждый член комиссии выводится отдельной строкой;
порядок вывода членов комиссии должен соответствовать порядку, указанному в документе тн_ПриказНаКомиссиюПоИнвентаризации.
Вариант 2. Комиссия отсутствует
Если документт тн_ПриказНаКомиссиюПоИнвентаризации отсутствует:
блок комиссии в печатной форме не выводится;
остальные элементы печатной формы формируются без изменений.

5. Алгоритм формирования печатной формы
При формировании печатной формы необходимо выполнить следующие действия:
Получить реквизиты документа «Внутреннее потребление (Списание на расходы)».
Заполнить типовую печатную форму документа.
Заполнить дополнительные реквизиты:
Через кого;
Затребовал;
Разрешил.
В разделе «Примечание» сформировать дополнительную таблицу «Материальные ценности. Заполнить дополнительную таблицу по данным табличной части Товары документа.
Проверить заполнение документа тн_ПриказНаКомиссиюПоИнвентаризации.
Если приказ заполнен:
получить председателя комиссии;
получить членов комиссии;
вывести блок комиссии.
Если приказ отсутствует:
не выводить блок комиссии.
Сформировать печатную форму.
