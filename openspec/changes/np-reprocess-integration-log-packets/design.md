## Context

Входящие сообщения `tn_integrationERP` обрабатывает `тн_Интеграция_ERP_УХ.ПолучениеСообщенийRMQ`. Успешный пакет удаляется из `тн_Интеграция_ОчередьОбработкиСообщенийRMQ`. JSON остаётся в `тн_Интеграция_ЛогСообщений.XML_ПакетВходящий`, если у профиля включено `ВестиЛоги`. Форма лога повторно обработать пакет не умеет. Расширение ТН править нельзя.

## Goals / Non-Goals

**Goals:**
- Внешняя обработка НП для поиска и повторной загрузки пакетов из лога
- Вызов того же контура, что и при приёме из RMQ
- Без повторной отметки «доставлено» в RabbitMQ
- Опция поставить пакет обратно в очередь регламентника

**Non-Goals:**
- Правка ТН / типового менеджера `Сотрудники`
- Перехват `ЗаполнитьОбъект` (это отдельная доработка НП)
- Повторная отправка IntegrationTicket
- Массовая обработка без отбора (лимит выборки)

## Decisions

### 1. Внешняя обработка, не расширение

**Решение:** `ExternalDataProcessors/нп_ПовторнаяОбработкаПакетовИнтеграции/`, вид БСП «Дополнительная обработка», `БезопасныйРежим = Ложь`, команда открывает форму.

**Почему:** утилита администрирования обмена; не зависит от поставки ТН; собирается в `.epf` как остальные обработки НП.

### 2. Источник пакета — лог

**Решение:** читать `XML_ПакетВходящий` по измерениям `ВидИнтеграции` + `Ключ`. JSON выделять с первой `{` (в логе перед пакетом может быть служебный текст).

**Почему:** после успеха очередь пуста; лог — единственное штатное хранилище тела сообщения.

### 3. Повторный вызов без ticket

**Решение:** `тн_Интеграция_ERP_УХ.ПолучениеСообщенийRMQ(ТекстJSON, Неопределено, , Отказ, , Истина)` — шестой параметр `ОбработкаСообщенияRMQИзПромежуточногоРегистра = Истина`.

**Почему:** тот же движок заполнения объектов; ticket в RMQ не отправляется.

### 4. Очередь — отдельный режим

**Решение:** флажок «Поставить в очередь»: `тн_Интеграция_ОчередьОбработкиСообщенийRMQ.ДобавитьСообщение`. `ПолучениеСообщенийRMQ_БезОбработки` не использовать (отсев дублей по хешу).

## Risks / Trade-offs

- Без `ВестиЛоги` пакета в логе нет — обработка это показывает
- Повтор без доработки заполнения `ФизическоеЛицо` снова оставит реквизит пустым
- `ПОДОБНО` по телу пакета на большом логе может быть медленным — обязателен период и лимит
