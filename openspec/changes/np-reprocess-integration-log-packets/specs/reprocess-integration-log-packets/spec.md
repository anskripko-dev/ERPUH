## ADDED Requirements

### Requirement: External processor registration
Система SHALL предоставлять дополнительную обработку «Повторная обработка пакетов интеграции (НП)», регистрируемую через «Дополнительные отчёты и обработки».

#### Scenario: Open form command
- **WHEN** обработка зарегистрирована и пользователь вызывает её команду
- **THEN** открывается форма поиска и повторной обработки пакетов

### Requirement: Search packets in integration log
Обработка SHALL находить записи `РегистрСведений.тн_Интеграция_ЛогСообщений` с непустым `XML_ПакетВходящий` по периоду, опционально по виду сообщения, ИД сообщения, базе-респонденту и подстроке в теле пакета. Выборка SHALL быть ограничена лимитом.

#### Scenario: Find catalogEmployees by period
- **WHEN** задан период и вид сообщения `catalogEmployees`
- **THEN** в таблице показываются записи лога входящих пакетов этого вида за период (не более лимита)

#### Scenario: Find by object guid in packet body
- **WHEN** в поле поиска указан GUID объекта, встречающийся в `XML_ПакетВходящий`
- **THEN** в результат попадают только записи, тело которых содержит эту подстроку

#### Scenario: Empty incoming packet skipped
- **WHEN** у записи лога `XML_ПакетВходящий` пустой
- **THEN** запись не попадает в выборку

### Requirement: Reprocess selected packets
По отмеченным строкам обработка SHALL извлечь JSON из `XML_ПакетВходящий` и повторно загрузить его штатным контуром `тн_Интеграция_ERP_УХ.ПолучениеСообщенийRMQ` с признаком обработки из промежуточного регистра (без IntegrationTicket). По каждой строке SHALL быть записан результат (успех, отказ или текст исключения).

#### Scenario: Immediate reprocess
- **WHEN** пользователь отмечает найденный пакет и нажимает «Обработать выбранные» без режима очереди
- **THEN** вызывается `ПолучениеСообщенийRMQ` с `ОбработкаСообщенияRMQИзПромежуточногоРегистра = Истина`

#### Scenario: Put back into RMQ processing queue
- **WHEN** включён режим «Поставить в очередь» и пользователь обрабатывает выбранные
- **THEN** текст пакета записывается в `тн_Интеграция_ОчередьОбработкиСообщенийRMQ` для регламентной обработки

#### Scenario: Missing JSON reported
- **WHEN** в `XML_ПакетВходящий` нет JSON-объекта (нет символа `{`)
- **THEN** строка не загружается, в результате указывается, что пакет не найден
