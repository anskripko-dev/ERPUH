## Why

Планируется бесшовная интеграция с 1С:Документооборот. Нужно запрещать проведение документов до завершения согласования в ДО. Типовая интеграция синхронизирует статусы и запускает маршруты, но **не блокирует проведение** сама по себе. Для «Перемещение товаров» и других типов без реквизита согласования нужен **универсальный** механизм в расширении НП, подключаемый настройкой без копипасты в каждый модуль объекта.

## What Changes

- Универсальный контроль проведения по состоянию согласования в 1С:Документооборот в расширении `uhnp.НП` (префикс `нп_`)
- Настройки по типу объекта + организации (вкл. контроль, дата начала действия)
- Серверная проверка в `ПередЗаписью` при `РежимЗаписи = Проведение` по типовому РС `СостоянияСогласованияВДокументообороте`
- **Защита от проведения после существенных изменений** при состоянии `НаСогласовании` / `Согласован`: белый список разрешённых реквизитов; при существенных изменениях — вопрос пользователю, прерывание и перезапуск обработки в **ДО 3**, проведение только после нового согласования
- Отображение состояния согласования на форме документа
- Роль обхода контроля для аварийных сценариев
- Первичное подключение: `Документ.ПеремещениеТоваров`

## Capabilities

### New Capabilities

- `do-posting-approval-control`: настраиваемый запрет проведения до согласования в ДО; защита проведения при существенных изменениях согласованного / находящегося на согласовании документа с перезапуском обработки ДО 3; отображение статуса на форме

### Modified Capabilities

- (нет — в `openspec/specs/` ещё нет зафиксированных capabilities по интеграции с ДО)
