# Контроль проведения по согласованию ДО (расширение НП)

Реализация OpenSpec change `np-do-posting-approval-control`.

Префикс объектов: **`нп_`**.

Служебная копия для переноса (без удаления из `uhnp.НП`):  
`Extensions/нп_КонтрольПроведенияПоДО/`

## Объекты

| Объект | Назначение |
|---|---|
| `РС.нп_НастройкиКонтроляПроведенияПоДО` | Настройки по полному имени метаданных + организации |
| `ОпределяемыйТип.нп_ДокументыКонтроляПроведенияПоДО` | Источник подписки (сейчас — `ПеремещениеТоваров`) |
| `Подписка.нп_КонтрольПроведенияПоДОПередЗаписьюДокумента` | `ПередЗаписью` → проверка проведения |
| `ОМ.нп_КонтрольПроведенияПоСогласованиюДО` | API и логика |
| `ОМ.нп_КонтрольПроведенияПоСогласованиюДОПовтИсп` | Кэш настроек |
| `Роль.нп_ОбходКонтроляСогласованияДО` | Обход контроля |
| `Подсистема.нп_КонтрольПроведенияПоДО` | Объединяет объекты доработки |
| `&После` `МодификацияКонфигурацииПереопределяемый.ПриСозданииНаСервере` | Статус на форме |

Источник истины статуса: `ОбъектыИнтегрированныеС1СДокументооборотом` + `СостоянияСогласованияВДокументообороте` (без веб-вызова на проведение).

## Внедрение

1. Опубликовать расширение `НП` (`uhnp.НП`).
2. В панели БИД включить:
   - интеграцию с 1С:Документооборот (2.x и/или 3.x);
   - `ИспользоватьСогласованиеЧерез1СДокументооборот`.
3. Создать правило интеграции ДО для `Документ.ПеремещениеТоваров` и маршрут согласования.
4. Заполнить настройку (один раз):

```bsl
нп_КонтрольПроведенияПоСогласованиюДО.УстановитьНастройкуПоУмолчаниюДляПеремещенияТоваров(Организация);
```

Или вручную в РС `Настройки контроля проведения по ДО`:
- Полное имя: `Документ.ПеремещениеТоваров`
- Организация: нужная организация
- Контролировать: Да

Настройка задаётся **отдельно для каждой организации**. При включённом контроле проведение возможно только после согласования в ДО. Организация без записи в РС не контролируется.
5. Назначить роль `Обход контроля согласования ДО` узкому кругу (перепроведение старых документов, аварийный обход). Полноправные пользователи обходят контроль автоматически.

## Подключение нового типа документа

1. Добавить `DocumentObject.<Имя>` в определяемый тип `нп_ДокументыКонтроляПроведенияПоДО`.
2. Добавить строку в РС настроек (полное имя + политика).
3. Настроить правило интеграции в ДО.
4. Опубликовать расширение.

## Проверка в ИБ

- [ ] Перемещение без связи с ДО + политика «Всегда» → проведение запрещено
- [ ] На согласовании / Не согласован → запрещено
- [ ] Согласован → проведение разрешено
- [ ] Запись без проведения и отмена проведения → не блокируются
- [ ] Роль обхода / полный доступ → проведение разрешено
- [ ] Тип без настройки в РС → не затрагивается
- [ ] На форме отображается поле «Согласование ДО»
