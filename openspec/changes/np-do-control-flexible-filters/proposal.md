## Why

Условия «тип + организация + дата» недостаточны: нужно гибко ограничивать, когда требуется согласование в ДО — по реквизитам документа и по пользователям/группам, по тому же паттерну, что в проекте «Обработчики событий».

## What Changes

- В настройке контроля: отбор СКД по реквизитам (`ОтборПоРеквизитам`) и список участников включая/исключая.
- Пустые отборы = применимо ко всем (как в evh_).
- Проверка при проведении и при пересогласовании; полноправные тоже проходят отбор по пользователям (авто-обхода полноправия нет).
- Обходчик СКД и UX компоновщика — по образцу evh_, без зависимости от расширения evh_.

## Capabilities

### New Capabilities

- `do-control-flexible-filters`: гибкие отборы применимости контроля проведения по ДО

### Modified Capabilities

- `do-posting-approval-control` (change `np-do-posting-approval-control`): расширяется модель настроек

## Impact

- `РС.нп_НастройкиКонтроляПроведенияПоДО`, форма записи
- ОМ контроля + новый клиент-серверный модуль обходчика
- Перечисление видов строк участников; заимствование `ГруппыПользователей`
- Пакет `Extensions/нп_КонтрольПроведенияПоДО`
