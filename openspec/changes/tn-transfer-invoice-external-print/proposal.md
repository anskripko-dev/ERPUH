## Why

По заявке **ERP.2026.12** для документа «Перемещение товаров» нужна внешняя печатная форма «Накладная на перемещение», аналогичная уже сделанным М-11 и МБ-7. Типовая ПФ выводит область «Подписи» пустой (только подписи для заполнения от руки). Заказчику нужно заполнять **Отпустил** / **Получил** материально ответственными складов-отправителя и получателя, с учётом регистра замещения: если на дату документа ответственного кто-то замещает — в ПФ выводить замещающего.

## What Changes

- Новая внешняя печатная форма (обработка БСП «Дополнительные отчёты и обработки», вид «Печатная форма») для `Документ.ПеремещениеТоваров`
- Формирование на базе типовой `СформироватьПечатнуюФормуНакладнойНаПеремещениеТоваров` (шапка, ТЧ товаров, серии/упаковки — как в типовой)
- Заполнение подписей:
  - **Отпустил** — `СкладОтправитель.ТекущийОтветственный` (+ должность склада)
  - **Получил** — `СкладПолучатель.ТекущийОтветственный` (+ должность склада)
  - при активном замещении на дату документа — ФИО замещающего из `РегистрСведений.Заместители` (при нескольких — последний по `ДатаНачала`); должность заместителя — из кадровых данных
- штатная команда печати остаётся рядом (не заменяется)
- Исходники — в `ExternalDataProcessors/` репозитория ERPUH (типовой менеджер документа не правится)

## Capabilities

### New Capabilities
- `transfer-invoice-external-print`: внешняя ПФ накладной на перемещение с заполнением Отпустил/Получил из МОЛ складов и учётом замещения

### Modified Capabilities
- (нет)

## Impact

- Документ: `ПеремещениеТоваров` (`СкладОтправитель`, `СкладПолучатель`)
- Склады: `ТекущийОтветственный` (`ФизическиеЛица`), `ТекущаяДолжностьОтветственного`
- Замещение: `РегистрСведений.Заместители` (`ЗамещаемыйПользователь` / `Заместитель` — `Пользователи`, период `ДатаНачала`…`ДатаОкончания`); связь с МОЛ через `Пользователи.ФизическоеЛицо`
- Типовой эталон: `Документ.ПеремещениеТоваров` / макет `ПФ_MXL_НакладнаяНаПеремещение`
- Эталон структуры внешней ПФ: `ExternalDataProcessors/тн_ПФ_М11_ВнутреннееПотребление`, `тн_ПФ_МБ7_ВнутреннееПотребление`
- Регистрация в ИБ через доп. отчёты и обработки; сборка `.epf` по `Instructions/внешние-обработки.md`
