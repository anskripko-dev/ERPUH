## Context

Документ `НастраиваемыйОтчет` не проводится; значения пишутся в независимые РС по ключу `Версия` (`Справочник.ВерсииЗначенийПоказателей`, владелец — `ОписаниеВерсий`). Типовая обработка «Копирование экземпляров отчетов» работает только внутри одной ИБ.

## Goals / Non-Goals

**Goals:**
- Выгрузить один или несколько экземпляров в XML-файл
- Загрузить файл в рабочую базу с цифрами
- Сохранить GUID документа и версий (сценарий «копия той же ИБ»)
- Регистрация через БСП «Дополнительные отчёты и обработки»

**Non-Goals:**
- Перенос НСИ (виды отчётов, показатели, аналитики)
- Присоединённые файлы и состояние согласования
- COM-соединение с другой ИБ
- Правка типовых объектов конфигурации

## Decisions

### 1. Внешняя обработка, не расширение

Можно открыть в копии и в рабочей базе без обновления конфигурации.

### 2. Формат файла — XML + XDTO

Корень `нп_ПакетЭкземпляровОтчетов` (`ВерсияФормата="1.0"`), блок `Описание`, далее объекты `СериализаторXDTO` с `НазначениеТипаXML.Явное`. Порядок: документы → описания версий → версии → наборы регистров (отбор по `Версия`).

### 3. Какие версии и регистры

По умолчанию: не помеченные на удаление, активные, не черновые. Опции: выгружать неактивные и черновые.

Регистры — все РС с измерением `Версия` и именем `ЗначенияПоказателейОтчетов*`, `ЗначенияПоказателейМоделирование*`, `КомментарииЗначенийПоказателей`. Пустые наборы не пишутся.

### 4. Загрузка

`ОбменДанными.Загрузка = Истина`, привилегированный режим. Перед записью объектов из файла для каждого экземпляра из блока `Описание` удаляются существующие `ВерсииЗначенийПоказателей` (и их наборы РС) и связанные `ОписаниеВерсий`. Иначе в приёмнике остаются старые версии с другими GUID, и бланк суммирует цифры.

Набор регистра записывается с `Записать(Истина)` по отбору `Версия`. Флаг «Замещать существующие»: если ложь и документ уже есть — шапку не трогать, версии и цифры всё равно заменить данными из файла.

Объекты в файле читаются **по имени узла** (`DocumentObject.` → `ДокументОбъект.` и т.д.), затем `СериализаторXDTO.ПрочитатьXML(ЧтениеXML, ТипОбъекта)`.

### 5. Права

`БезопасныйРежим = Ложь`. Перед записью документа типовой `ПередЗаписью` проверяет матрицу доступа **до** проверки `ОбменДанными.Загрузка` — нужны права на запись вида отчёта.

## Risks / Trade-offs

- [Разъехавшаяся НСИ] GUID показателей/аналитик в приёмнике другие → битые ссылки. Обработка пишет предупреждение, не откатывает пакет.
- [Большой файл] макеты документа (хранилища значений) попадают в XML. Приемлемо для точечного переноса.
- [Замена версий] все версии загружаемого экземпляра в приёмнике удаляются, даже те, которых нет в файле.
