## Why

Цифры экземпляра отчёта (`Документ.НастраиваемыйОтчет`) хранятся не в документе, а в версиях и регистрах сведений. Штатное копирование/выгрузка только документа из копии ИБ даёт пустую форму. Нужен перенос документа **вместе со значениями показателей** через файл.

## What Changes

- Внешняя обработка `нп_ВыгрузкаЗагрузкаЭкземпляраОтчета`: выгрузка выбранных экземпляров в XML и загрузка этого файла в другую ИБ той же конфигурации
- В файл входят: документ, `ОписаниеВерсий`, `ВерсииЗначенийПоказателей`, наборы `ЗначенияПоказателейОтчетов*` / моделирование / комментарии по этим версиям
- Запись в приёмнике с `ОбменДанными.Загрузка = Истина` и сохранением GUID (копия той же ИБ)
- Исходники — `ExternalDataProcessors/нп_ВыгрузкаЗагрузкаЭкземпляраОтчета/` (префикс `нп_`; типовая конфигурация не меняется)

## Capabilities

### New Capabilities
- `export-import-report-instance`: файловый перенос экземпляра отчёта вместе с цифрами

### Modified Capabilities
- (нет)

## Impact

- Документ: `НастраиваемыйОтчет`
- Справочники: `ОписаниеВерсий`, `ВерсииЗначенийПоказателей`
- Регистры сведений с измерением `Версия` и префиксом `ЗначенияПоказателейОтчетов` / `ЗначенияПоказателейМоделирование`, плюс `КомментарииЗначенийПоказателей`
- Справочники НСИ (показатели, аналитики, организации) не выгружаются — в копии той же ИБ GUID совпадают
- Сборка `.epf` и регистрация в доп. обработках по образцу других внешних обработок НП
