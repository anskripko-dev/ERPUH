## ADDED Requirements

### Requirement: Export report instance with indicator values
Система SHALL выгружать выбранные документы `НастраиваемыйОтчет` в XML-файл вместе с описаниями версий, версиями значений показателей и записями регистров сведений, ключ которых — эти версии.

#### Scenario: File contains document and values
- **WHEN** пользователь указывает экземпляр отчёта с заполненными показателями и выполняет выгрузку
- **THEN** файл содержит документ, связанные `ОписаниеВерсий` и `ВерсииЗначенийПоказателей`, и наборы регистров `ЗначенияПоказателейОтчетов*` по этим версиям

#### Scenario: Active versions only by default
- **WHEN** выгрузка выполняется с включённым флажком «Только активные версии» и выключенным «Выгружать черновые»
- **THEN** в файл не попадают помеченные на удаление, неактивные и черновые версии

#### Scenario: Empty selection is rejected
- **WHEN** таблица экземпляров пуста или в ней нет заполненных ссылок
- **THEN** выгрузка не выполняется, пользователю показывается сообщение

### Requirement: Import report instance from file
Система SHALL загружать XML-пакет в текущую ИБ, записывая объекты с исходными GUID и `ОбменДанными.Загрузка = Истина`, а наборы регистров — с заменой записей по измерению `Версия`.

#### Scenario: Values appear after load
- **WHEN** файл, выгруженный из копии той же ИБ, загружается в приёмник
- **THEN** экземпляр открывается с теми же цифрами, что были в источнике

#### Scenario: XDTO objects are read by element name
- **WHEN** в пакете после `Описание` идут узлы `DocumentObject.*`, `CatalogObject.*`, `InformationRegisterRecordSet.*` (в том числе с `xmlns` и `xsi:type`)
- **THEN** загрузка определяет тип 1С по локальному имени узла и записывает объекты, даже если `ВозможностьЧтенияXML` возвращает ложь

#### Scenario: Unknown XML nodes are reported
- **WHEN** в пакете встречается узел, который нельзя сопоставить с документом, справочником или набором РС
- **THEN** узел пропускается, в протоколе есть строка «Пропущен неизвестный узел XML»

#### Scenario: Existing document header can be kept
- **WHEN** документ с тем же GUID уже есть и «Замещать существующие» выключен
- **THEN** шапка документа в приёмнике не перезаписывается, версии и значения из файла записываются

#### Scenario: Invalid file is rejected
- **WHEN** выбран файл без корня `нп_ПакетЭкземпляровОтчетов`
- **THEN** загрузка не выполняется, в протоколе фиксируется ошибка формата

### Requirement: Additional data processor registration
Обработка SHALL регистрироваться в подсистеме «Дополнительные отчёты и обработки» как дополнительная обработка с командой открытия формы.

#### Scenario: Command opens the form
- **WHEN** обработка зарегистрирована и пользователь вызывает её команду
- **THEN** открывается форма с вкладками выгрузки и загрузки
