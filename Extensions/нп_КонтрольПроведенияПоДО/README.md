# Служебное расширение: контроль проведения по согласованию ДО

Копия доработок OpenSpec `np-do-posting-approval-control` для переноса в другие ИБ / EDT-проекты.

**Исходники в `uhnp.НП` не удалялись** — эта папка дублирует объекты для поставки.

Префикс объектов: **`нп_`**.

## Состав

| Объект | Назначение |
|---|---|
| `РС.нп_НастройкиКонтроляПроведенияПоДО` | Настройки по типу + организации |
| `ОпределяемыйТип.нп_ДокументыКонтроляПроведенияПоДО` | Источник подписки (`ПеремещениеТоваров`) |
| `Подписка.нп_КонтрольПроведенияПоДОПередЗаписьюДокумента` | Запрет проведения |

| `Подсистема.нп_КонтрольПроведенияПоДО` | Объединяет объекты доработки |
| `МодификацияКонфигурацииПереопределяемый` (`&После`) | Статус на форме |

При включённом контроле проведение возможно только после согласования в ДО.

## Перенос

1. Импортировать каталог `src` как расширение EDT (или собрать `.cfe`).
2. Подключить к ERP УХ с БИД и согласованием через ДО.
3. Не подключать одновременно с теми же объектами внутри `uhnp.НП` (совпадающие UUID).
4. После публикации:

```bsl
нп_КонтрольПроведенияПоСогласованиюДО.УстановитьНастройкуПоУмолчаниюДляПеремещенияТоваров(Организация);
```

Настройка — **по организации** (измерения: полное имя метаданных + организация).
