# Служебное расширение: контроль проведения по согласованию ДО

Копия доработок OpenSpec `np-do-posting-approval-control` для переноса в другие ИБ / EDT-проекты.

**Исходники в `uhnp.НП` не удалялись** — эта папка дублирует объекты для поставки.

Префикс объектов: **`нп_`**.

## Расположение

```
C:\Projects\ERPUH\Extensions\нп_КонтрольПроведенияПоДО\
  README.md
  нп_КонтрольПроведенияПоДО.cfe  ← готовое расширение для загрузки в базу
  docs\             ← Архитектура решения, Методика испытаний
  src\              ← формат EDT (*.mdo)
  configurator\     ← выгрузка конфигуратора (Configuration.xml)
```

## Быстрая установка

Конфигурация → Расширения → **Добавить из файла** → `нп_КонтрольПроведенияПоДО.cfe`.

## Состав

| Объект | Назначение |
|---|---|
| `РС.нп_НастройкиКонтроляПроведенияПоДО` | Настройки по типу + организации; отбор СКД по реквизитам; участники включая/исключая |
| `Перечисление.нп_ВидыСтрокУчастниковКонтроля` | Включая / Исключая |
| `РС.нп_ПроверяемыеРеквизитыПриСогласованииДО` | Реквизиты, изменение которых требует пересогласования |
| `РС.нп_ПризнакиПересогласованияДО` | Признак необходимости пересогласования (`DocumentRef`) |
| `Подписка.нп_КонтрольПроведенияПоДОПередЗаписьюДокумента` | Источник — все `DocumentObject`; ранний выход по настройкам |
| `ОМ.нп_КонтрольПроведенияПоСогласованиюДО` | API и логика |
| `ОМ.нп_КонтрольПроведенияПоСогласованиюДОКлиентСервер` | Отбор СКД |
| `ОМ.нп_КонтрольПроведенияПоСогласованиюДОПовтИсп` | Кэш настроек и списка проверяемых реквизитов |
| `Подсистема.нп_КонтрольПроведенияПоДО` | Объединяет объекты доработки |
| `Отчет.нп_СогласованныеНеПроведенныеПеремещения` | Согласованные, но не проведённые перемещения |
| `Справочник.Организации` | Заимствование для типа измерения |

Документы в расширение **не** заимствуются. Типовые модули форм не расширяются. Состав контролируемых типов — только записи РС настроек.

При включённом контроле проведение возможно только после согласования в ДО. Существенные изменения при записи → серверное сообщение; прерывание и повторный запуск обработки ДО 3; проведение — после нового согласования. Исключения из контроля — через отбор участников в настройке (включая/исключая), отдельной роли обхода нет.

На форме настройки: **отбор по реквизитам** (СКД) и **участники** (пользователи/группы, включая/исключая). Пустые отборы = применимо ко всем. Исключающая строка отсекает даже при вхождении во включающую группу.

## Перенос в конфигуратор

1. Конфигурация → Расширения конфигурации → создать/открыть расширение (назначение **Адаптация**, префикс `нп_`).
2. Конфигурация → **Загрузить конфигурацию из файлов…**
3. Указать каталог:

```
C:\Projects\ERPUH\Extensions\нп_КонтрольПроведенияПоДО\configurator
```

В корне должен быть `Configuration.xml`. Каталог `src` **не** грузить.

4. Обновить конфигурацию БД расширения и включить его.

Соответствие с основной конфигурацией — **по имени** (`KeepMapping…ByIDs = false`).

Если был «конфликт внутренних идентификаторов» у `Справочник.Организации` / `Пользователи` / `ГруппыПользователей`:
1. Удалите из расширения старое заимствование этого справочника (если уже есть).
2. Загрузите `configurator` заново **или** создайте чистое расширение и загрузите туда.
3. Не подключайте этот пакет одновременно с `uhnp.НП` в одной ИБ (дубли объектов / UUID).

Если был конфликт у других объектов — создайте чистое расширение и загрузите `configurator` заново.

## Перенос в EDT

Импорт из `src` или обновление уже существующего `uhnp.НП` (объекты уже там).

Не подключать одновременно эту копию и те же объекты внутри `uhnp.НП` (совпадающие UUID).

После публикации:

```bsl
нп_КонтрольПроведенияПоСогласованиюДО.УстановитьНастройкуПоУмолчаниюДляПеремещенияТоваров(Организация, ДатаНачалаДействия);
```

или вручную — запись в РС настроек с выбором документа из списка.
