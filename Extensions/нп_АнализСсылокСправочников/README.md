# Служебное расширение: анализ ссылок номенклатуры и контрагентов

Отчёт мест использования элементов справочников **Номенклатура** и **Контрагенты** с произвольным отбором (включая дополнительные реквизиты), группировкой ссылок по типу значения и количеством.

Префикс объектов: **`нп_`**.

## Расположение

```
C:\Projects\ERPUH\Extensions\нп_АнализСсылокСправочников\
  README.md
  src\              ← формат EDT (*.mdo)
  configurator\     ← выгрузка конфигуратора (Configuration.xml)
```

Имя расширения: `нп_АнализСсылокСправочников`  
Назначение: Customization  
Соответствие заимствований: **по имени** (`KeepMappingToExtendedConfigurationObjectsByIDs = false`).

## Состав

| Объект | Назначение |
|---|---|
| `Отчет.нп_МестаИспользованияНоменклатурыИКонтрагентов` | Список элементов и ссылок на них |
| `Подсистема.нп_АнализСсылокСправочников` | Команда отчёта |
| `Справочник.Номенклатура` | Заимствование |
| `Справочник.Контрагенты` | Заимствование |

## Поведение отчёта

- Параметр **Вид справочника**: Номенклатура (по умолчанию) или Контрагенты; два варианта СКД.
- Отбор СКД по полям справочника и **дополнительным реквизитам** (характеристики набора `Справочник_Номенклатура` / `Справочник_Контрагенты`; для номенклатуры также наборы видов номенклатуры).
- По умолчанию: не группы, не помеченные на удаление.
- Для каждого элемента — все ссылки (`ОбщегоНазначения.МестаИспользования` / `НайтиПоСсылкам`), группы по типу значения (синоним объекта метаданных), количество ссылок.
- Элементы без ссылок остаются в отчёте с количеством 0.
- Параметр **Лимит элементов** (по умолчанию 1000) ограничивает поиск ссылок.

## Установка в конфигуратор

1. Конфигурация → Расширения конфигурации → создать расширение (назначение **Адаптация**, префикс `нп_`).
2. Конфигурация → **Загрузить конфигурацию из файлов…**
3. Указать каталог:

```
C:\Projects\ERPUH\Extensions\нп_АнализСсылокСправочников\configurator
```

В корне должен быть `Configuration.xml`. Каталог `src` **не** грузить.

4. Обновить конфигурацию БД расширения и включить его.

Не подключать этот пакет одновременно с копией тех же объектов внутри `uhnp.НП` в одной ИБ.

## Перенос в EDT

Импорт из `src` в отдельный проект расширения либо перенос объектов в `uhnp.НП` с сохранением префикса `нп_`.

Файл `.cfe` в этой поставке не собирается (нужна платформа 1С на стенде).
