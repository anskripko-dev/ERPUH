# Служебное расширение: анализ ссылок номенклатуры и контрагентов

Два отчёта мест использования элементов справочников **Номенклатура** и **Контрагенты** с произвольным отбором (включая дополнительные реквизиты), группировкой ссылок по типу значения и количеством.

Префикс объектов: **`нп_`**.

## Расположение

```
C:\Projects\ERPUH\Extensions\нп_АнализСсылокСправочников\
  README.md
  src\              ← формат EDT (*.mdo)
  configurator\     ← выгрузка конфигуратора (Configuration.xml)
```

## Состав

| Объект | Назначение |
|---|---|
| `Отчет.нп_МестаИспользованияНоменклатуры` | Список номенклатуры и ссылок на неё |
| `Отчет.нп_МестаИспользованияКонтрагентов` | Список контрагентов и ссылок на них |
| `Подсистема.нп_АнализСсылокСправочников` | Команды отчётов |
| `ОбщаяФорма.ВводЗначенийСпискомСФлажками` | Заимствование: в списке с флажками можно отметить только выделенные строки |
| `ОбщаяФорма.ВыборОбъектовМетаданных` | Заимствование: объекты внутри групп Справочники/Документы/… по алфавиту |
| `Справочник.Номенклатура` | Заимствование |
| `Справочник.Контрагенты` | Заимствование |

## Поведение отчётов

### Номенклатура

- Колонки: Код, Наименование, тн_ЯвляетсяОбъектомЦБ + анализ использования.
- Отбор по доп. реквизитам (набор `Справочник_Номенклатура` + наборы видов номенклатуры).
- По умолчанию: не группы, не помеченные на удаление.
- Быстрый отбор: **Группа финансового учета** (InList).

### Контрагенты

- Колонки: Наименование, ИНН, КПП, Партнер, тн_ЯвляетсяОбъектомЦБ + анализ использования.
- Отбор по доп. реквизитам (набор `Справочник_Контрагенты`).
- По умолчанию: не помеченные на удаление.
- Сортировка: ИНН, КПП, Наименование.

### Общее

- Поиск ссылок по умолчанию: запросы `КОЛИЧЕСТВО` по реквизитам и измерениям нужного типа (без списка каждого объекта).
- Параметр **Выводить ссылающиеся объекты (медленно)** включает `НайтиПоСсылкам` порциями по 1000; для выборок больше 5000 элементов остаётся режим количеств.
- Параметр **Типы ссылок** и **Отбор по типам ссылок**:
  - **Не учитывать эти типы** (как раньше): элемент попадает в отчёт, только если есть ссылки помимо указанного списка. Любой тип вне списка оставляет элемент в отчёте.
  - **Исключить при наличии этих типов**: элемент не выводится, если есть хотя бы одна ссылка типа из списка.
  - Выбор типов — типовое дерево БСП (Справочники, Документы, регистры, задачи…). Внутри группы объекты по алфавиту (синоним).
- Группировка по умолчанию: элемент → тип значения и количество ссылок.
- Параметр **Лимит элементов** (по умолчанию 1000). Для сотен тысяч элементов детальный список объектов не использовать.
- Фиксированная схема СКД без подмены запроса и без параметра «Вид справочника».

## Установка в конфигуратор

1. Конфигурация → Расширения конфигурации → создать расширение (назначение **Адаптация**, префикс `нп_`).
2. Конфигурация → **Загрузить конфигурацию из файлов…** → каталог `configurator`.
3. Обновить конфигурацию БД расширения и включить его.

Предпочтительная установка без расширения — внешние отчёты:

- `ExternalReports/нп_МестаИспользованияНоменклатуры/`
- `ExternalReports/нп_МестаИспользованияКонтрагентов/`

Команды **Отметить выделенные** относятся к типовой форме списка с флажками. Для параметра типов снова открывается дерево метаданных; сортировка внутри групп — в расширении и в патче `uhnp`.
