# Места использования номенклатуры

Внешний отчёт СКД: список **номенклатуры** с произвольным отбором (включая дополнительные реквизиты) и количеством ссылок по типам метаданных.

Исходники: `ExternalReports/нп_МестаИспользованияНоменклатуры/`

## Открытие без .erf

В **конфигураторе базы ERP УХ**: **Файл → Открыть** → `нп_МестаИспользованияНоменклатуры.xml`.

## Сборка .erf

См. `.tools/build-external-report-erf.ps1` с параметром `-ReportName нп_МестаИспользованияНоменклатуры`.

## Поведение

- Отбор по полям справочника и доп. реквизитам (набор `Справочник_Номенклатура` + наборы видов номенклатуры).
- По умолчанию: не группы, не помеченные на удаление. В результате элементы выводятся в иерархии справочника (группы-родители как узлы дерева).
- Быстрый отбор: **Группа финансового учета** (InList). Можно отбирать по родителю (в иерархии).
- Колонки: Элемент справочника, Код, Наименование, тн_ЯвляетсяОбъектомЦБ + анализ использования.
- Поиск ссылок по умолчанию: запросы `КОЛИЧЕСТВО` по реквизитам/измерениям нужного типа (без `НайтиПоСсылкам` и без списка каждого объекта).
- Параметр **Выводить ссылающиеся объекты (медленно)** включает детальный список через `НайтиПоСсылкам` порциями по 1000; для выборок больше 5000 элементов принудительно остаётся режим количеств.
- Параметр **Типы ссылок** и рядом **Отбор по типам ссылок**:
  - **Не учитывать эти типы** (как раньше): элемент попадает в отчёт, только если есть ссылки помимо указанного списка. Без ссылок и с типами только из списка — не выводится.
  - **Исключить при наличии этих типов**: элемент не выводится, если есть хотя бы одна ссылка типа из списка. Без ссылок и с другими типами — выводится.
  - Выключенный список типов — все отобранные элементы. Выбор типов — дерево по видам (Справочники, Документы, …); сортировка внутри группы по алфавиту — в расширении или патче `uhnp`.
- Лимит элементов (по умолчанию 1000). Для больших объёмов (десятки/сотни тысяч) оставляйте детальный список выключенным и сужайте отбор.
