# Места использования номенклатуры

Внешний отчёт СКД: список **номенклатуры** с произвольным отбором (включая дополнительные реквизиты) и всеми ссылками на каждый элемент, сгруппированными по типу значения, с количеством.

Исходники: `ExternalReports/нп_МестаИспользованияНоменклатуры/`

## Открытие без .erf

В **конфигураторе базы ERP УХ**: **Файл → Открыть** → `нп_МестаИспользованияНоменклатуры.xml`.

## Сборка .erf

См. `.tools/build-external-report-erf.ps1` с параметром `-ReportName нп_МестаИспользованияНоменклатуры`.

## Поведение

- Отбор по полям справочника и доп. реквизитам (набор `Справочник_Номенклатура` + наборы видов номенклатуры).
- По умолчанию: не группы, не помеченные на удаление.
- Быстрый отбор: **Группа финансового учета** (InList).
- Колонки: Код, Наименование, тн_ЯвляетсяОбъектомЦБ + анализ использования.
- Лимит элементов (по умолчанию 1000).
