# Места использования контрагентов

Внешний отчёт СКД: список **контрагентов** с произвольным отбором (включая дополнительные реквизиты) и всеми ссылками на каждый элемент, сгруппированными по типу значения, с количеством.

Исходники: `ExternalReports/нп_МестаИспользованияКонтрагентов/`

## Открытие без .erf

В **конфигураторе базы ERP УХ**: **Файл → Открыть** → `нп_МестаИспользованияКонтрагентов.xml`.

## Сборка .erf

См. `.tools/build-external-report-erf.ps1` с параметром `-ReportName нп_МестаИспользованияКонтрагентов`.

## Поведение

- Отбор по полям справочника и доп. реквизитам (набор `Справочник_Контрагенты`).
- По умолчанию: не помеченные на удаление.
- Сортировка: ИНН, КПП, Наименование.
- Колонки: Наименование, ИНН, КПП, Партнер, тн_ЯвляетсяОбъектомЦБ + анализ использования.
- Поиск ссылок: `ОбщегоНазначения.МестаИспользования` порциями по 1000 элементов.
- Лимит элементов (по умолчанию 1000).
