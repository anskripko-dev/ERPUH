# Места использования контрагентов

Внешний отчёт СКД: список **контрагентов** с произвольным отбором (включая дополнительные реквизиты) и количеством ссылок по типам метаданных.

Исходники: `ExternalReports/нп_МестаИспользованияКонтрагентов/`

## Открытие без .erf

В **конфигураторе базы ERP УХ**: **Файл → Открыть** → `нп_МестаИспользованияКонтрагентов.xml`.

## Сборка .erf

См. `.tools/build-external-report-erf.ps1` с параметром `-ReportName нп_МестаИспользованияКонтрагентов`.

## Поведение

- Отбор по полям справочника и доп. реквизитам (набор `Справочник_Контрагенты`).
- По умолчанию: не помеченные на удаление.
- Сортировка: ИНН, КПП, Наименование.
- Колонки: Наименование, ИНН, КПП, Партнер, тн_ЯвляетсяОбъектомЦБ + анализ использования.
- Поиск ссылок по умолчанию: запросы `КОЛИЧЕСТВО` по реквизитам/измерениям нужного типа (без `НайтиПоСсылкам` и без списка каждого объекта).
- Параметр **Выводить ссылающиеся объекты (медленно)** включает детальный список через `НайтиПоСсылкам` порциями по 1000; для выборок больше 5000 элементов принудительно остаётся режим количеств.
- Лимит элементов (по умолчанию 1000). Для больших объёмов (десятки/сотни тысяч) оставляйте детальный список выключенным и сужайте отбор.
