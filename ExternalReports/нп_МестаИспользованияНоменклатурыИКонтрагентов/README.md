# Места использования номенклатуры и контрагентов

Внешний отчёт СКД: список **номенклатуры** или **контрагентов** с произвольным отбором (включая дополнительные реквизиты) и всеми ссылками на каждый элемент, сгруппированными по типу значения, с количеством.

Исходники: `ExternalReports/нп_МестаИспользованияНоменклатурыИКонтрагентов/`

## Без .erf — сразу из XML

В **конфигураторе базы ERP УХ**:

1. **Файл → Открыть** → файл `нп_МестаИспользованияНоменклатурыИКонтрагентов.xml` (в этом каталоге).
2. Отчёт откроется для просмотра и проверки.
3. При необходимости: **Файл → Сохранить как…** → `нп_МестаИспользованияНоменклатурыИКонтрагентов.erf`.

Это единственный надёжный способ получить рабочий `.erf`. Утилиты вроде v8unpack упаковывают XML в контейнер v8, но **не** в бинарный формат платформы — такой файл в 1С выглядит пустым.

## Сборка .erf (Windows, платформа 1С)

Нужна база **ERP УХ** (не пустая файловая база).

```powershell
.\.tools\build-external-report-erf.ps1 `
  -V8Path "C:\Program Files\1cv8\8.3.24.1691\bin" `
  -InfoBasePath "C:\Bases\ERP_UH"
```

Для серверной базы:

```powershell
.\.tools\build-external-report-erf.ps1 `
  -V8Path "C:\Program Files\1cv8\8.3.24.1691\bin" `
  -InfoBaseServer "srv01" `
  -InfoBaseRef "ERP_UH" `
  -UserName "Admin" `
  -Password "secret"
```

Результат: `нп_МестаИспользованияНоменклатурыИКонтрагентов.erf` в этом каталоге.

Файл `.erf` в git **не хранится** — его собирают на стенде с установленной платформой 1С.

## Использование

- **Файл → Открыть** → `.erf` — сразу открывается форма отчёта (в базе ERP).
- Или регистрация в **Дополнительные отчёты и обработки**:
  - вид: дополнительный отчёт;
  - безопасный режим: выключен (`НайтиПоСсылкам` / привилегированный режим БСП);
  - разделы по умолчанию: Склад, Продажи, Закупки (можно сменить при регистрации).

## Поведение

- Параметр **Вид справочника**: Номенклатура (по умолчанию) / Контрагенты.
- Отбор СКД по полям справочника и доп. реквизитам.
- По умолчанию: не группы, не помеченные на удаление.
- Группировка: элемент → тип значения → ссылающийся объект; количество ссылок.
- Лимит элементов (по умолчанию 1000).
