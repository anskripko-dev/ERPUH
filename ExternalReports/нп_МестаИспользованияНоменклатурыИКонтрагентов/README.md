# Места использования номенклатуры и контрагентов

Внешний отчёт СКД: список **номенклатуры** или **контрагентов** с произвольным отбором (включая дополнительные реквизиты) и всеми ссылками на каждый элемент, сгруппированными по типу значения, с количеством.

Исходники: `ExternalReports/нп_МестаИспользованияНоменклатурыИКонтрагентов/`

## Сборка .erf

1. Конфигуратор **в базе ERP** → **Файл → Открыть** → каталог `нп_МестаИспользованияНоменклатурыИКонтрагентов` (файл `нп_МестаИспользованияНоменклатурыИКонтрагентов.xml`).
2. **Файл → Сохранить как…** → `нп_МестаИспользованияНоменклатурыИКонтрагентов.erf`.

Файл `.erf` в репозитории не собирается (нужна платформа 1С на стенде).

## Использование

- **Файл → Открыть** → `.erf` — сразу открывается форма отчёта.
- Или регистрация в **Дополнительные отчёты и обработки**:
  - вид: дополнительный отчёт;
  - безопасный режим: выключен (`НайтиПоСсылкам` / привилегированный режим БСП);
  - разделы по умолчанию: Склад, Продажи, Закупки (можно сменить при регистрации).

## Поведение

- Параметр **Вид справочника**: Номенклатура (по умолчанию) / Контрагенты.
- Отбор СКД по полям справочника и доп. реквизитам.
- По умолчанию: не группы, не помеченные на удаление.
- Группировка: элемент → тип значения → ссылающийся объект; количество ссылок.
- Лимит элементов (по умолчанию 1000).
