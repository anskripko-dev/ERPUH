# Согласованные, но не проведенные перемещения

Внешний отчёт (СКД) для контроля документов **Перемещение товаров**, успешно согласованных в 1С:Документооборот, но ещё не проведённых.

По умолчанию: статус согласования = **Согласован**, документ **не проведён**.

| Поле | Источник |
|---|---|
| Статус / дата согласования / согласующий | `СостоянияСогласованияВДокументообороте` (`Состояние`, `ДатаУстановки`, `Установил`) |
| Связь с ДО | `ОбъектыИнтегрированныеС1СДокументооборотом` |
| Реквизиты документа | дата, номер, организация, склады, ответственный, проведён, автор |
| Отбор «Подразделение» | `ПеремещениеТоваров.Подразделение` |

Исходники: `ExternalReports/нп_СостояниеСогласованияДОПеремещений/`

## Сборка .erf

Готовый файл: `нп_СостояниеСогласованияДОПеремещений.erf` (рядом с XML).

CLI (пустая файловая ИБ, платформа 8.3.27):

```text
1cv8.exe DESIGNER /F <путь_к_ИБ> /DisableStartupDialogs
  /LoadExternalDataProcessorOrReportFromFiles
  <…>\нп_СостояниеСогласованияДОПеремещений.xml
  <…>\нп_СостояниеСогласованияДОПеремещений.erf
```

Или вручную в конфигураторе ERP: **Файл → Открыть** → XML → **Сохранить как…** → `.erf`.

Подробнее: `C:\Projects\Instructions\внешние-обработки.md`, стандарты СКД — `C:\Projects\Instructions\скд-стандарты-разработки-отчетов.md`.

## Регистрация в ИБ

1. **Дополнительные отчёты и обработки** → загрузить `.erf`.
2. Публикация: использовать.
3. Команда: «Согласованные, но не проведенные перемещения».

Безопасный режим включён.

## Проверка

| Сценарий | Ожидание |
|---|---|
| Согласован + не проведён | Строка в отчёте; заполнены статус, при наличии обмена — дата и согласующий |
| Согласован + проведён | Не попадает при отборах по умолчанию |
| На согласовании / нет связи с ДО | Не попадает (нет статуса Согласован / нет связи) |
| Отбор орг. / подразделение / склад / ответственный / период | Только подходящие документы |
| Сортировка по умолчанию | Дата, затем номер |
