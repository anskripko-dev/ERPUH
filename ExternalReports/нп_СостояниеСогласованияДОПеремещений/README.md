# Состояние согласования ДО по перемещениям

Внешний отчёт (СКД) по документам **Перемещение товаров** с состоянием согласования в 1С:Документооборот.

Источник статуса — типовые регистры БИД (без веб-вызова в ДО):

- `РегистрСведений.ОбъектыИнтегрированныеС1СДокументооборотом`
- `РегистрСведений.СостоянияСогласованияВДокументообороте`

Колонка **Требуется пересогласование** — из РС расширения `нп_ПризнакиПересогласованияДО` (расширение `нп_КонтрольПроведенияПоДО`).

Представления состояния совпадают с API контроля проведения:

| Ситуация | Представление |
|---|---|
| Нет записи связи | Нет связи с Документооборотом |
| Связь есть, состояние пусто | Связан с ДО, состояние не задано |
| Есть состояние | Представление перечисления |

Исходники: `ExternalReports/нп_СостояниеСогласованияДОПеремещений/`

## Сборка .erf

Готовый файл: `нп_СостояниеСогласованияДОПеремещений.erf` (рядом с `нп_СостояниеСогласованияДОПеремещений.xml`).

CLI (пустая файловая ИБ, платформа 8.3.27):

```text
1cv8.exe DESIGNER /F <путь_к_ИБ> /DisableStartupDialogs
  /LoadExternalDataProcessorOrReportFromFiles
  <…>\нп_СостояниеСогласованияДОПеремещений.xml
  <…>\нп_СостояниеСогласованияДОПеремещений.erf
```

Либо вручную: конфигуратор **в базе ERP с загруженным расширением контроля ДО** → **Файл → Открыть** → `нп_СостояниеСогласованияДОПеремещений.xml` → **Файл → Сохранить как…** → `.erf`.

Без расширения контроля при открытии/проверке схемы в полной ИБ может не хватать `нп_ПризнакиПересогласованияДО` — либо подключите расширение, либо временно уберите JOIN и колонку из запроса СКД.

Подробнее об общем контуре внешних объектов: `C:\Projects\Instructions\внешние-обработки.md`.  
Стандарты СКД: `C:\Projects\Instructions\скд-стандарты-разработки-отчетов.md`.

## Регистрация в ИБ

1. **НСИ и администрирование → Печатные формы, отчёты и обработки → Дополнительные отчёты и обработки**.
2. Создать элемент, загрузить `.erf` (вид — дополнительный отчёт).
3. Публикация: использовать; при необходимости указать раздел интерфейса.
4. Открыть команду «Состояние согласования ДО по перемещениям».

Безопасный режим включён (`БезопасныйРежим = Истина`) — отчёт только читает данные.

## Проверка

| Сценарий | Ожидание |
|---|---|
| Перемещение без связи с ДО | «Нет связи с Документооборотом», `ЕстьСвязьСДО = Нет` |
| Связь есть, состояние ещё не пришло | «Связан с ДО, состояние не задано» |
| Состояние `НаСогласовании` / `Согласован` / `НеСогласован` | Соответствующее представление |
| В РС признака пересогласования установлен флаг | Колонка «Требуется пересогласование» = Да |
| Отбор по периоду / организации | В выборке только подходящие документы |
| Помеченные на удаление | По умолчанию скрыты (отбор «Пометка удаления = Нет») |
